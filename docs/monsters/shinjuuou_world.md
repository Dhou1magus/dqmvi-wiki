# 神獣王WORLD

コインボス。「神獣王WORLDのコイン」を使うと専用の闘技場へ飛び、戦えます。倒すと、通常ドロップとして神獣王の戦篭手・神獣王の兜・神獣王の鎧・神獣王の籠手・神獣王のレギンスのどれか1つをかならず落とします。
闘技場では、神獣王WORLDの力で強化とアクセサリーの力が封じられます。
