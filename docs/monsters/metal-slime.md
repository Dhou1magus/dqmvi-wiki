# メタルスライム

スライム系 ・ 出現レア度 ★★★★☆ ・ 仲間化 可

::: warning このページはテンプレートです
数値・出現条件はレイアウト確認用のサンプルであり、実際のDQMVIのデータではありません。
検証した実データに差し替えてから公開してください。
:::

逃走率が非常に高いかわりに、討伐時の獲得経験値が突出して大きいモンスター。夜間の平原・岩山バイオームに低確率でスポーンし、プレイヤーを視認すると数秒でデスポーンする。物理攻撃はほぼ通らないため、会心か固定ダメージ手段を用意してから挑むのが基本になる。

## 仲間にする条件

::: tip なかまモンスター

1. 討伐時に **1/64** の確率で「メタルスライムのこころ」を落とす
2. こころを持った状態で [まもの使い](/jobs/) のレベルを 20 以上にする
3. モンスターじいさんに話しかけると加入する
:::

## 攻略のコツ

* 守備力が極端に高いため通常攻撃はほぼ1ダメージ。会心必中系の特技か、守備力を無視する「まじん斬り」を用意する
* 初手でボミオスを入れると逃走判定までの猶予が伸び、討伐成功率が体感で倍近くになる
* 湧き潰しをした平原に高さ3のガラス箱を作っておくと、逃走してもデスポーンしにくい
* マルチプレイでは湧き上限を共有するため、狩り場を分散させたほうが効率が良い
