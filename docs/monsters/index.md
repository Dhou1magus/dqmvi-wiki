# モンスター図鑑

::: warning このページはテンプレートです
掲載している数値はレイアウト確認用のサンプルです。実データに差し替えてください。
:::

## ページの追加方法

新しいモンスターのページを作るときは、[メタルスライムのページ](/monsters/metal-slime)を丸ごとコピーして中身を書き換えるのがいちばん早いです。
詳しくは [編集のしかた](/guide/edit) を参照してください。
