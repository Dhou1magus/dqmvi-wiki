# ほのおの盾

盾・アクセサリー。**3体**のモンスターが落とします。

::: tip ねらい目
**ドラゴンゾンビ**（超レアドロップ・EXP171）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

| 項目 | 内容 |

| しゅび | ×1.16 |
