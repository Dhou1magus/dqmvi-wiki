# もろはのつるぎ

武器。**1体**のモンスターが落とします。

::: tip ねらい目
**ぼうれい剣士**（超レアドロップ・EXP270）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 武器（剣） |
| こうげき | 20 |
| 攻撃倍率 | ×3.88 |
| 特殊効果 | 与えたダメージの1/10のダメージを受ける |

倍率は、いまの能力に掛かる値です。
