# 女神のイヤリング

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**エンゼルアーマー**（通常ドロップ・EXP32,464）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| しゅび | ×1.25 |
| 魔法しゅび | ×1.25 |
| 特殊効果 | 呪文・炎ダメージを30％減 |
