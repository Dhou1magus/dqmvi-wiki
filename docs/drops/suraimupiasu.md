# スライムピアス

盾・アクセサリー。**2体**のモンスターが落とします。

::: tip ねらい目
**スライム**（超レアドロップ・EXP2）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| --- | --- |

| HP | ×1.02 |
| しゅび | ×1.02 |
