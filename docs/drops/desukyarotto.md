# デス・キャロット

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**ウサンダー**（通常ドロップ・EXP3,861）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 武器（ドリル） |
| こうげき | 10 |
| 攻撃倍率 | ×1.25 |
| 特殊効果 | 正面の3×3マスをまとめて掘る |

倍率は、いまの能力に掛かる値です。
