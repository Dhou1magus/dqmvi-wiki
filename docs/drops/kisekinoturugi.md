# 奇跡の剣

武器。**1体**のモンスターが落とします。

::: tip ねらい目
**キラーマシン2**（超レアドロップ・EXP931）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

| 項目 | 内容 |

| 攻撃倍率 | ×2.91 |
| 特殊効果 | 1/5の確立で与えたダメージの1/10を回復する |
