# やみのころも

盾・アクセサリー。**1体**のモンスターが落とします。

::: tip ねらい目
**ゾーマ**（通常ドロップ・EXP6,776,767）。
コインボスで、倒すとかならず落とします。
:::

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| 特殊効果 | 受けるダメージが半分になる代わりに、自分の回復量も半分になる |
