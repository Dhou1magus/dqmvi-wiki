# 勇車の笛(弱)

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**プチリンガル**（通常ドロップ・EXP22,892）。
いちばん出やすい枠で落とすモンスターのうち、いちばん弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| MP | ×1.15 |
| まりょく | ×1.15 |
| 特殊効果 | 装備中、呪文のダメージを0.6倍する代わりに詠唱時間を0.8倍にする |

倍率は、今の能力に掛かる値です。
