# 神の涙

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**ゴメちゃん**（通常ドロップ・EXP8,564）。
いちばん出やすい枠で落とすモンスターのうち、いちばん弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| HP | ×1.25 |
| しゅび | ×1.25 |
| 魔法しゅび | ×1.25 |
| 特殊効果 | ピンチでザオリク(最大HPの1/4で復活・10秒間会心率+20%・1時間に1度) |

倍率は、今の能力に掛かる値です。
