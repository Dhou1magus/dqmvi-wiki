# 神獣王の戦篭手

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**神獣王WORLD**（通常ドロップ・EXP6,238,631）。
コインボスで、倒すと神獣王の戦篭手・神獣王の兜・神獣王の鎧・神獣王の籠手・神獣王のレギンスのどれか1つをかならず落とします。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 武器（戦籠手） |
| こうげき | 40 |
| 攻撃倍率 | ×4 |
| 特殊効果 | 攻撃が当たったとき、自分と相手それぞれ50%で悪い効果(デバフ)を全て消す |

倍率は、いまの能力に掛かる値です。
