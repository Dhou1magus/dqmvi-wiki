# スライムボックス

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**モモンジャガー**（通常ドロップ・EXP21,642）。
コインボスで、倒すとかならず落とします。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| HP | ×1.15 |
| しゅび | ×1.15 |
| 特殊効果 | モンスターが仲間になる確率が上がる |

倍率は、いまの能力に掛かる値です。
