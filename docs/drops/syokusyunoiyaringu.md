# 触手のイヤリング

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**メーダプリンス**（通常ドロップ・EXP8,635）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| HP | ×1.15 |
| MP | ×1.2 |
| まりょく | ×1.2 |
| 特殊効果 | 呪文を溜めている間、守備と魔守が2倍 |

倍率は、いまの能力に掛かる値です。
