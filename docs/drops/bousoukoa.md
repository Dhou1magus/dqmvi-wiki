# 暴走コア

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**ファイアボール**（通常ドロップ・EXP7,321）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| まりょく | ×2 |
| 特殊効果 | 毎秒HPが3〜5%減る |

倍率は、いまの能力に掛かる値です。
