# デスマスク

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**デスマシーン**（通常ドロップ・EXP8,187）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| こうげき | ×1.2 |
| しゅび | ×1.15 |
| 魔法しゅび | ×1.15 |
| 特殊効果 | ダメージを受けた際、5%でバイキルト |
