# ドロップ品から探す

モンスターが落とすアイテムは **213種** です。
欲しいアイテムを押すと、それを落とすモンスターが全部出ます。

::: tip 見かた
**ねらい目**は、落とす枠がいちばん手前（通常＞レア＞超レア）で、
そのなかで一番弱い相手です。数を集めたいときはここから狩るのが早いです。

飾りの「オブジェ」と「フィギュア」は数が多すぎて目的の品が埋もれるため載せていません。
モンスターのページを見れば、そのモンスターが落とす飾りが分かります。
:::
