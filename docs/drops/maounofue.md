# 魔王の笛

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**大魔王オン・ゾ・エーグ**（通常ドロップ・EXP6,423,533）。
コインボスで、倒すとかならず落とします。
:::

| 項目 | 内容 |
| --- | --- |
