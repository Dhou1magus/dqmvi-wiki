# 竜のうろこ

盾・アクセサリー。**2体**のモンスターが落とします。

::: tip ねらい目
**しっぽ団のキラーマシン**（超レアドロップ・EXP169）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::
