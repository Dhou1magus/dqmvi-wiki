# シャ攻の戦籠手

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**シャコウ鬼神**（通常ドロップ・EXP24,638）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 武器（戦籠手） |
| こうげき | 20 |
| 攻撃倍率 | ×3 |
| 特殊効果 | 手に持っていると、1度に受けるダメージが最大HPの50%を超えない |

倍率は、いまの能力に掛かる値です。
