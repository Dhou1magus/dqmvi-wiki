# にくきゅうの杖

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**ミケまどう**（通常ドロップ・EXP1,980）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 武器（杖） |
| こうげき | — |
| 攻撃倍率 | ×1.5 |
| 特殊効果 | 単体魔法を三方向に放つ(メラ系・ヒャド系・ドルマ系のみ) |

倍率は、いまの能力に掛かる値です。
