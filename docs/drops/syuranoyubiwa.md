# 修羅の指環

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**アスラ王**（通常ドロップ・EXP23,454）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| HP | ×1.25 |
| こうげき | ×1.25 |
| 特殊効果 | 30%で通常攻撃が4回攻撃(1倍・0.75倍・0.5倍・0.25倍) |

倍率は、いまの能力に掛かる値です。
