# はめつの盾

盾・アクセサリー。**1体**のモンスターが落とします。

::: tip ねらい目
**がいこつけんし**（超レアドロップ・EXP225）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | 盾 |
| しゅび | ×1.4 |
| 魔法しゅび | ×1 |
| 構え中 | ×3 |
| 特殊効果 | 防御力が半分になる |

倍率は、いまの能力に掛かる値です。
