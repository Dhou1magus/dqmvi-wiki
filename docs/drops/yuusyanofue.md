# 勇車の笛

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**スラリンガル**（通常ドロップ・EXP6,663,242）。
コインボスで、倒すとかならず落とします。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| MP | ×1.25 |
| まりょく | ×1.25 |
| 特殊効果 | 装備中、呪文のダメージを0.8倍する代わりに詠唱時間を0.5倍にする |

倍率は、いまの能力に掛かる値です。
