# 全てを超越せし者討伐の証

素材。**1体**のモンスターが落とします。

::: tip ねらい目
**全てを超越せし者**（通常ドロップ・EXP5,000,000）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::
