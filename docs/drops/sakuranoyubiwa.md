# サクラの指輪

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**さくらこぞう**（通常ドロップ・EXP985）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

## 装備としての性能

| 項目 | 内容 |
| --- | --- |
| 種類 | アクセサリー |
| しゅび | ×1.17 |
| 魔法しゅび | ×1.17 |
| 特殊効果 | 手に入る経験値が10%増える |

倍率は、いまの能力に掛かる値です。
