# キラーパイクのピッケル

転生装備。**1体**のモンスターが落とします。

::: tip ねらい目
**キラーピッケル**（通常ドロップ・EXP2,120）。
落とす枠がいちばん手前で、そのなかで一番弱い相手です。
:::

| 項目 | 内容 |

| 攻撃倍率 | ×1.5 |
