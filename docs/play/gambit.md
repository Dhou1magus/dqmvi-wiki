# ガンビット

ペットに戦い方を指示するガンビットの組み方。

## ガンビット

### ガンビットとは

ペットの動きを自分でルールにして組む仕組み。

1枚のルールは『対象＋条件1＋条件2＋行動』の4つでできている。

上から順に見て、最初に当てはまった1枚だけを実行する。並べ替えがそのまま戦い方になる。

### 使いはじめ方

Zメニューの『ガンビット編集』を開く。近く24マスに自分のペットがいるときだけ組める。

画面右上の『さくせんをガンビットにする』を押すと、そのペットがルールで動くようになる。

もう一度押すと元のさくせんへ戻る。押した時点で待機だったペットは追従に起こす。

### 組み方の手順

右の4列(対象/条件1/条件2/行動)から1つ選び、左のルール欄をクリックして置く。

置いてあるガンビットは左クリックで持ち上げて別の場所へ移せる。右クリックで外して手元に戻る。

各行の右端にある▲▼で、そのルールの優先順位を入れ替えられる。

### ルールの枚数

使える枚数はペットのレベルで増える。Lv1で3枚、Lv99以上で12枚。

枠を超えたぶんは保存されない。配合や転生で生まれた子は枠がLv1ぶんに戻るので、親のルールは引き継がず、組んであったガンビットは飼い主の手元へ返る。

### ガンビットは装備

ガンビットはアイテム。1つのスロットに置くと1個消費し、外すと戻ってくる。

同じ種類を数だけ持っていれば、何匹にでも同じルールを組める。

大きな袋の中身も数に入る。

### 対象の選び方

『自分』はペット自身、『主』は飼い主のこと。

味方とペットは同じ飼い主の他のペット、パーティは同じパーティの人。

敵は種族・メタル系・魔王系・きらきら個体などで絞り込める。

### 条件の噛み合わせ

条件1には『条件2が要るもの』と『要らないもの』がある。

HP・MPには◯%以下、距離には◯マス以内、数には◯体以上、というように種類の合うものだけ組める。

噛み合っていない行には赤い×が出る。×にマウスを乗せると理由が読める。

### 受け皿を置く

どのルールにも当てはまらないと、ペットはその場から動かない。

一番下に『主／常に／追従』のような受け皿を1枚置いておくと、平時はついて歩くようになる。

例: HP50%以下なら追従 → 敵がいれば戦う → それ以外は主について歩く。

### 待機で止まる

ペットを『待機』にしている間、ガンビットは丸ごと止まる。休ませたいときは待機にすればよい。

攻撃・追従・迎撃のときはルールで動く。

ガンビット中は『対象の強さ』の絞り込みと、性格による逃げ腰を無視してルールを優先する。

### 型とマイセット

編集画面の下にある『型・マイセット』から、組んだ内容を名前を付けて30個まで保存できる。

保存した型は他のペットにも流し込める。『コピー』『貼り付け』で1匹ぶんだけ写すこともできる。

こちらで用意した型(アタッカー・ヒーラー・ほじょ・かべなど7種)も同じ場所から呼び出せる。

### 働かせる

対象に『木材・石材・土・砂・砂利・鉱石・育った作物』を選び、行動を『壊す』にすると採ってくる。

『ドロップアイテム』＋『回収して渡す』にすると、落ちている物を拾って飼い主へ渡す。

渡し先は自動回収ONの大きな袋→持ち物→足元の順。伐採役と回収役を並べると流れ作業になる。

### 働かせるときの決まり

掘る対象は、行けると分かった場所だけを狙う。埋まったブロックや届かない場所は選ばない。

土・砂・砂利・石材・作物は飼い主の高さ±1マスだけを見る。木材と鉱石は上下8マスまで見る。

ブロックを置けない場所では壊さない。

### ガンビットの集め方

宝箱から出る。色が良いほど出やすい(赤30%/黒40%/青50%/緑60%/紫70%/金80%)。

道具屋では『敵(全て)』『自分』『常に』『たたかう』『待機する』を各1000Gで売っている。

まずは店で最初の1枚を組み、足りないものを宝箱で集めるとよい。
