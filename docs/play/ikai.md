# 異界（世界8〜10）

防衛戦でランク7を制覇すると行けるようになる、3つの世界。ふだんの世界より強いモンスターが出る。

## 世界の一覧

| 世界 | 名前 | バイオーム | 次へ進むには |
| --- | --- | --- | --- |
| 世界8 | 天空の古代大陸 | 雲海・天空の草原・古代の森・白亜の高地 | 突破戦に勝って「世界9のゲート」を手に入れる |
| 世界9 | 氷晶世界 | 凍てつく海・氷柱の森・青氷の氷河 | 突破戦に勝って「世界10のゲート」を手に入れる |
| 世界10 | 崩壊神殿世界 | 溶岩の海・ひび割れた大地・玄武岩の尖塔・神殿の廃墟 | 4つの祠の封印を解き、崩壊神殿の最深部へ進む |

## 異界へ行く

### 世界8のゲート

防衛戦でランク7を制覇すると、ごほうびで「世界8のゲート」がもらえる。

防衛戦ランク7を制覇していないと、ゲートから先へは進めない。

### 移動のしかた

ゲートを置いて使うと、その世界へ飛ぶ。連れている仲間も一緒に移動する。

元の世界へ戻るときは「帰還の台座」を使う。

## オーブと突破戦（世界8・9）

### 6つのオーブ

世界8と世界9には、それぞれ6つのオーブがある。その世界で次のことをすると手に入る。

| オーブ | 手に入れ方 |
| --- | --- |
| レッド | その世界のダンジョンをクリアする |
| ブルー | その世界で魚を釣る（150匹に1回ほど） |
| グリーン | その世界のモンスターを3匹仲間にする |
| イエロー | その世界の金の宝箱を開ける（15%） |
| パープル | その世界のメタル系を倒す（30体に1回ほど） |
| シルバー | その世界のバイオームをすべて見つける |

### 突破戦

6つのオーブがそろうと、「突破戦の台座」で突破戦に挑める。闘技場は入口から東へ約512マス。

突破戦をクリアすると、次の世界のゲートが1個手に入る。

## 崩壊神殿（世界10）

世界10には炎・氷・闇・魔の4つの祠がある。4つの封印がすべて解けると、崩壊神殿の最深部への道が開く。最深部は、到着地点から西へ約768マス。

## 異界の装備

異界で手に入る装備には「異界の」と付く。性能は、同じ種類でいちばん強い装備の1.05〜1.30倍で、元の装備が強いほど倍率が高い。

## 勇者の試練

人間の仲間は、異界では試練を乗り越えるまで本当の力を出せない。

異界でルイーダの「勇者の試練に挑む」を選ぶと始まる。受けられるのはLv300の仲間だけ。

仲間がひとりで3体の敵を倒せば合格。制限時間は3分で、仲間が倒れるか時間切れになると失敗。

乗り越えた仲間は、その世界までの異界で本当の力を出せるようになる。
