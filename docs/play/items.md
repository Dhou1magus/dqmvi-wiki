## 種・作物

### 叡智の種

交配種。食べると魔力1.15倍(5分)+MP回復(10秒毎+5を1分)。異なる系統の作物を隣どうしで育てて収穫すると稀に採れる

### 剛力の種

交配種。食べると攻撃力と守備力が1.15倍(5分)。異なる系統の作物を隣どうしで育てて収穫すると稀に採れる

### 真・極黄金の種

真・極黄金の実の苗。畑に植えて育てると真・極黄金の実が採れる。黄金系の最上位で、育てるには極黄金の種から品質を上げる必要がある

### 真・極黄金の実

黄金系の最上位。食べると攻撃力・守備力・魔力がまとめて2.0倍(5分)。無印1.15倍 / 超1.35倍 / 極1.6倍 / 真・極2.0倍。力・守り・魔力の種とは重ねられない(黄金を使うと単体の種の効果は消える)。ペットに与えても同じ効果が出る

### 力の種

食べると攻撃力アップ(5分)。無印1.1倍 / 超1.3倍 / 極1.5倍。

### 守りの種

食べると守備力アップ(5分)。無印1.1倍 / 超1.3倍 / 極1.5倍。

### 魔力の種

食べると魔力アップ(5分)。無印1.1倍 / 超1.3倍 / 極1.5倍。

### 素早さの種

食べると歩く速度アップ(5分)。無印2倍 / 超3倍 / 極4倍。

### 黄金の実

食べると攻撃力・守備力・魔力がまとめてアップ(5分)。無印1.15倍 / 超1.35倍 / 極1.6倍 / 真・極2.0倍。

### 炎の実

食べると炎の被ダメージを軽減(5分)。無印3/4 / 超1/2 / 極1/4。

### いやしの実

食べると10秒ごとにHPが回復(1分)。無印+10 / 超+20 / 極+40。

### 魔法の実

食べると10秒ごとにMPが回復(1分)。無印+5 / 超+10 / 極+20。

### 薬草

使うとHP回復。無印30前後 / 超80前後 / 極250前後。序盤から終盤までお世話になる基本の回復アイテム。

### 毒消し草

毒を治す。超はHP30前後、極はHP80前後も同時に回復。

### 種の品質と育て方

どの種・実も畑で育てて増やせる。品質は無印→超→極の3段階(黄金のみ真・極まで4段階)で、上の品質ほど効果が大きい。

## 特殊効果のある武具

### 特殊効果とは

一部の武器・防具・アクセサリには、攻撃力とは別の効果が付いている。

効果は鍛冶画面の「効果」欄と、アイテムの説明に出る。

### 効果の種類

種族特効(ゾンビ・ドラゴン・悪魔・魔獣・メタルに2倍)

属性攻撃(炎・氷・風。相手の弱点と合えば2倍)

状態異常・即死・2回攻撃・会心率アップ

HP/MPの自動回復・耐性・解毒

採掘速度・水中速度・透明・暗視・経験値アップ

### 呪文が撃てる武具

右クリックでギラ・ヒャダルコ・バギクロス・ライデインを撃てるものがある。

撃つと耐久が3減る。

### セット効果

「◯つセットで」と書かれた効果は、DQMの防具をその数だけ身につけていると発動する。

鍛冶画面には「(防具4点で発動)」のように条件も出る。

## 道具

### 肉と捕獲

肉を投げて食べさせ、食べている間に倒すと仲間になりやすい。

くんせいにく4%、ほねつきにく8%、しもふりにく16%。鍛冶で作れる(肉系＋素材)。

転生系と魔王系、ボスオーラ付きは肉を食べない。それ以外はメタル系も食べる。

### ペット収納ベル

ペットをしまって持ち運ぶ道具。Shift+右クリックでしまう。

自動収納をONにしておくと、離れすぎたペットや、上限を超えたぶんが自動で入る。

中のペットは倒れたままでも入る。教会で治すか、出してからザオ系で起こす。

### 旅の扉とルーラ

ルーラは覚えた場所へ飛ぶ呪文。Shift+左クリック長押しでその場を記憶し、左クリック長押しで行き先を選ぶ。

リレミトは地下から地上へ脱出する。DQM設定で仲間も一緒に飛ぶようにできる。

旅の扉を置けば、決まった2点を行き来できる。
