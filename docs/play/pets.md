# ペットと配合

モンスターを仲間にして、育てて、配合するまで。

## 仲間にする

### 契約のしかた

野生のモンスターに近づいて右クリックすれば契約できる。気絶して倒れている子も契約できる(契約後にザオ系かせかいじゅの葉で起こそう)。

### 連れ歩ける数

一緒に連れ歩ける(ついてこいで追従できる)のは10匹まで。超えたぶんは指令のとき強制的に待機になる。待機も含めて世界に出せるのは50匹で、あふれた仲間は『ペット収納ベル』が預かってくれる。

### ペット収納ベル

しゃがみ+右クリックで収納、ベル使用でいつでも呼び出し。気絶中の子も収納できる。

## 指示と作戦

### ペットへの指示

待機・ついてこい・攻撃などのモードを切り替えられる。作業中は待機、探索はついてこいが基本。

### グループさくせん

全ペットまとめて作戦を変えられる。「ガンガンいこうぜ」「いのちだいじに」で立ち回りが変わる。

### 性格

仲間には性格があり、戦い方や退き際に個性が出る。

## フォーメーション

### フォーメーションとは

隊列を組むとペットとプレイヤー両方にバフがかかる。人数が揃うほど強力な陣形が選べる。

### F3〜F6の陣形

F3: 守備1.2倍 / F4: 攻撃1.2倍 / F5: 魔力1.2倍 / F6: 魔法守備1.2倍。

### F7〜F10の陣形

F7: 攻撃・魔力1.1倍 / F8: 魔力・守備1.1倍 / F9: 守備・魔法守備1.1倍 / F10: 攻撃・守備1.1倍。大人数の陣形はボス戦の切り札。

## 種族シナジー

### 種族シナジーとは

同じ種族の仲間を並べると1体あたり+2%のボーナス(2〜10体で+2〜18%)。ｽﾗｲﾑ=ぷるぷる連携(受ける回復量↑・ここだけ1体あたり+4%で+4〜36%) / 魔獣=群れの本能(攻撃↑) / 自然=大地の恵み(最大HP↑) / 物質=硬質連結(守備↑) / 悪魔=魔界の波動(魔力↑) / ｿﾞﾝﾋﾞ=不死の渇き(与えたダメージの一部をHP吸収)。ﾄﾞﾗｺﾞﾝ・特殊・ﾒﾀﾙにシナジーはない。

## 育成

### ペットのレベル

一緒に戦えば経験値が入りレベルアップ。ステータスの伸びは個体ごとに違う。

### 呪文・特技の習得

レベルが上がると新しい呪文を覚えることがある。固定で覚える呪文はLv10から始まりLv150で覚え終わる。ほかに、レベルが上がったときの抽選で覚える呪文もある。一度覚えた呪文は忘れない。

### ペット装備

ペットにも武器・盾・防具を持たせられる。働き者には作業Lvも育つ。

### 経験の聖典・性格の書

カジノ景品。経験の聖典はレベル+1、性格の書は性格をランダムに変える。

### 働かせて育てる

モンスターポートで働いているあいだ、ペットに経験値が入る。

防衛用は倒した相手の経験値が、そのポートのペット全員に入る。

ポートごとに1分あたりの上限があるので、頭数を増やしても伸びる速さは変わらない。

### ポートのペットが気絶したら

働いているペットが倒されると気絶して、そのポートに残る。

気絶中は働かないし経験値も入らない。

ポートから呼び出して、せかいじゅの葉かザオ系で起こす。

## 配合

### 配合のきほん

配合の杖を使うと、Lv20以上の2匹の仲間から新しい仲間が生まれる。親の力を受け継いで最初から強い。

配合の神官なら、Minecraft Lv10以上で収納ベル内の2匹をペットLv不問で選べる。Minecraft Lv10は配合・転生が成功した後に消費する。

### 配合ランク

配合を重ねるほど高ランクのモンスターに手が届く。

### 転生

転生の杖でLv20以上の2匹の仲間を使い、親Aの見た目のまま生まれ変わらせることができる。

### 血統と＋1

「＋数字」は配合・転生を重ねた世代数で、名前の横に出る。子は両親のうち大きい数字に「両親の合計Lv÷40」を足した数になる(最低＋1)。たとえば両親がLv100どうしなら＋5、Lv300どうしなら＋15。育ててから配合するほど数字が伸びる。

＋1ごとに装備・種バフを除いた基準能力の約10%ずつ継承が強くなり、＋10で約2倍。現在は上限なし。

生まれた子は親の血統も引き継ぐ。お気に入りの家系図を作るのも一興。

### 転生モンスターの印

仲間にした転生モンスターは、頭上の名前の横に「[転生]」、ベルの収納一覧とパーティ一覧では「転」と出る。

図鑑の「転生のみ」ボタンで、転生モンスターだけを並べられる(まだ会っていないものは出ない)。

## 配合の仕組み

子どもの候補は **親2匹のランクと系統** から決まります。
候補はひとつに定まらず、そこから **確率で抽選** されます。

配合画面には候補とその確率が並ぶので、決める前に何が生まれうるか確かめられます。
ランクも配合画面に出ます。配合を重ねるほど高いランクに手が届きます。

- 継承する魔法は、親Aと親Bから **最大5つ** まで選べます
- 実行すると親2匹は消えます。装備していたものはインベントリに戻ります
- 転生では見た目が親Aのまま変わらず、能力だけ引き継ぎます
