## 行動パターン

### 第1フェーズ（HP 100%〜60%）

この順番で上から繰り返します。

1. 防壁を張る（打撃に強くなる・20）
2. 呪文 **マヒャド**
3. 様子見（隙ができる）
4. 詠唱 **マヒャデドス**（4秒・打ち消し可）
5. いてつくはどう（こちらの強化を消す）

### 第2フェーズ（HP 60%〜25%）

この順番で上から繰り返します。

1. 詠唱 **マヒャデドス**（4秒・打ち消し可）
2. 氷属性の柱 5本
3. 様子見（隙ができる）
4. パワー溜め（3秒・次の一手が1.6倍）
5. 呪文 **イオナズン**
6. いてつくはどう（こちらの強化を消す）

### 第3フェーズ（HP 25%〜0%）

この順番で上から繰り返します。

1. パワー溜め（4秒・次の一手が1.6倍）
2. メテオ 3発
3. 詠唱 **マヒャデドス**（5秒・打ち消し可）
4. 後退して回復（HP6%ぶん・追撃のチャンス）
5. 氷属性の柱 7本
6. いてつくはどう（こちらの強化を消す）

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
