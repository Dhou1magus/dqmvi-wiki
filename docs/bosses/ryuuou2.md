## 行動パターン

### 第1フェーズ（HP 100%〜50%）

この順番で上から繰り返します。

1. 炎属性の柱 5本
2. 様子見（隙ができる）
3. パワー溜め（3秒・次の一手が1.6倍）
4. 呪文 **イオグランデ**
5. メテオ 3発

### 第2フェーズ（HP 50%〜0%）

この順番で上から繰り返します。

1. パワー溜め（4秒・次の一手が1.6倍）
2. メテオ 5発
3. 詠唱 **イオグランデ**（4秒・打ち消し可）
4. いてつくはどう（こちらの強化を消す）
5. 後退して回復（HP6%ぶん・追撃のチャンス）
6. 炎属性の柱 7本

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
