## 行動パターン

### 第1フェーズ（HP 100%〜50%）

この順番で上から繰り返します。

1. 呪文 **ザキ**
2. 様子見（隙ができる）
3. 呪文 **イオラ**
4. 呪文 **ラリホー**
5. 様子見（隙ができる）

### 第2フェーズ（HP 50%〜0%）

この順番で上から繰り返します。

1. 詠唱 **イオナズン**（4秒・打ち消し可）
2. 一番近い相手を檻に閉じ込める（6秒・壊して脱出可）
3. いてつくはどう（こちらの強化を消す）
4. パワー溜め（3秒・次の一手が1.6倍）
5. 呪文 **ザキ**
6. 衝撃波
7. 後退して回復（HP5%ぶん・追撃のチャンス）

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
