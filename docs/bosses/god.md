## 行動パターン

### 第1フェーズ（HP 100%〜70%）

この順番で上から繰り返します。

1. 光属性の柱 4本
2. 様子見（隙ができる）
3. 自己回復（最大HPの8%）
4. いてつくはどう（こちらの強化を消す）

### 第2フェーズ（HP 70%〜35%）

この順番で上から繰り返します。

1. 詠唱 **ミナデイン**（4秒・打ち消し可）
2. 光属性の柱 6本
3. 後退して回復（HP6%ぶん・追撃のチャンス）
4. 自己回復（最大HPの6%）
5. いてつくはどう（こちらの強化を消す）

### 第3フェーズ（HP 35%〜0%）

この順番で上から繰り返します。

1. 結界ドームに籠もる（5秒・無敵）
2. パワー溜め（4秒・次の一手が1.6倍）
3. メテオ 5発
4. 詠唱 **ビッグバン**（5秒・打ち消し可）
5. いてつくはどう（こちらの強化を消す）
6. 光属性の柱 8本

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
