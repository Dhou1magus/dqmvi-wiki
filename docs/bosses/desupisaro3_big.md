## 行動パターン

### 第1フェーズ（HP 100%〜60%）

この順番で上から繰り返します。

1. 衝撃波
2. メテオ 3発
3. 様子見（隙ができる）
4. 詠唱 **イオナズン**（3秒・打ち消し可）

### 第2フェーズ（HP 60%〜30%）

この順番で上から繰り返します。

1. 闇属性の柱 5本
2. いてつくはどう（こちらの強化を消す）
3. パワー溜め（3秒・次の一手が1.6倍）
4. メテオ 4発
5. 様子見（隙ができる）

### 第3フェーズ（HP 30%〜0%）

この順番で上から繰り返します。

1. パワー溜め（4秒・次の一手が1.6倍）
2. メテオ 6発
3. 詠唱 **ビッグバン**（5秒・打ち消し可）
4. いてつくはどう（こちらの強化を消す）
5. 後退して回復（HP6%ぶん・追撃のチャンス）
6. 衝撃波

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
