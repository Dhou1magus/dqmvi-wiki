## 行動の読み方

| 表記 | 意味 |
| --- | --- |
| いてつくはどう | こちらにかけた強化を全部消される |
| 詠唱 | 最大HPの8%ぶんダメージを与えると打ち消せる。守り切られると威力1.5倍 |
| パワー溜め | 次の一手が1.6倍。終わった直後に大きな隙ができる |
| 後退して回復 | 追撃のチャンス |
| 結界ドーム | 籠もっている間は無敵 |
