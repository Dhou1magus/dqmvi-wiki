## 行動パターン

### 第1フェーズ（HP 100%〜50%）

この順番で上から繰り返します。

1. 衝撃波
2. 呪文 **ルカニ**
3. 様子見（隙ができる）
4. 呪文 **ザキ**
5. 様子見（隙ができる）

### 第2フェーズ（HP 50%〜0%）

この順番で上から繰り返します。

1. 衝撃波
2. いてつくはどう（こちらの強化を消す）
3. 詠唱 **ザキ**（3秒・打ち消し可）
4. 闇属性の柱 4本
5. 後退して回復（HP5%ぶん・追撃のチャンス）

::: tip 詠唱と溜めが狙いどころ
`詠唱` 中は最大HPの8%ぶんのダメージを与えると打ち消せます。守り切られると威力が1.5倍になります。
`パワー溜め` の直後は大きな隙ができるので、そこで一気に削ります。
:::
