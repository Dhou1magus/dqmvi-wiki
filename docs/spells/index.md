## 効果の決まり方

- **炎・氷・爆発・風・闇・雷** … ダメージは「威力×魔力÷10」から相手の魔法守備を引いた値。魔力を伸ばすほど強くなる。
- **移動** … ダンジョンや洞窟から、その場所の地上へ脱出する。魔王の間とコインボスの闘技場では使えない。
- **補助** … 相手のMPを吸い取って自分のMPにする。
- **補助** … 眠っている自分や仲間を起こす。
- **補助** … マホトーンで封じられた呪文を使えるようにする。
- **補助** … 毒・麻痺などの状態異常を治す。
- **弱体** … 相手の素早さを下げる。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手を眠らせる。眠っている相手は動けない。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手の目をくらませる。かかった相手の打撃は半分がはずれる。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手の呪文を封じる。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手の守備力を下げる。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手を混乱させる。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手の攻撃力を半分にする。効果時間は魔力が高いほど伸びる。
- **弱体** … 相手にかかっている強化をすべて消す。効果時間は魔力が高いほど伸びる。
- **回復** … 自分や仲間、回復ターゲットに使える。
- **回復** … 少しずつ回復し続ける。自分や仲間、回復ターゲットに使える。
- **ザキ** … 即死率 20%。魔王系・転生系・ボス系・メタル系には無効。外れた場合はダメージを与えない。
- **バイキルト** … 効果 攻撃力を2倍にする。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **スカラ** … 効果 守備力を上げる。30秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **バイシオン** … 効果 攻撃力を1.5倍にする。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **スクルト** … 効果 周りの仲間全員の守備力を上げる。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **ピオリム** … 効果 周りの仲間全員の素早さを上げる。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **フバーハ** … 効果 周りの仲間全員の炎と吹雪のダメージを減らす。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **バーハ** … 効果 炎と吹雪のダメージを減らす。30秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **ピオラ** … 効果 素早さを上げる。30秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **マジックバリア** … 効果 周りの仲間全員の受ける呪文ダメージを減らす。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
- **マホカンタ** … 効果 相手の呪文をはね返す。45秒間続く。。自分や仲間、回復ターゲットにかけられる。効果時間は魔力が高いほど伸びる。
