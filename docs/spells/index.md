## 効果の決まり方

- **炎・氷・爆発・風・闇・雷・無属性・弱体** … ダメージは「威力+魔力×0.5−相手の魔法守備」。魔力を伸ばすほど強くなる。
- **回復** … 自分や仲間、回復ターゲットに使える。
- **補助** … 仲間や自分にかける補助効果。効果と時間は唱えて確かめよう。
- **ザキ** … 即死率 20%。魔王系・転生系・ボス系・メタル系には無効。外れた場合はダメージを与えない。
