# ご意見箱

この攻略wiki **そのもの** について思ったことを送ってください。
名前を書かなくても送れます。ひとつずつ全部読みます。

::: tip こんなことを書いてください
- 探していたものが見つからなかった
- 書いてあることが間違っている、古い
- このページがほしい、この情報を足してほしい
- 表が見づらい、スマホだと使いにくい
- そのほか、使っていて気になったこと
:::

::: warning MOD本体への要望は、ここからは作者に届きません
「DQMVIが起動しない」「このモンスターを追加してほしい」といったMOD本体の話は、
ここに書いても有志のwiki編集者に届くだけで、MODを作っている方には伝わりません。
不具合かどうか分からないときは、先に [よくある質問](/guide/faq) を見てみてください。
:::
