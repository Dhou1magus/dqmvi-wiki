# 編集のしかた

このwikiは有志の共同編集で作られています。**GitHubのアカウントさえあれば、ブラウザだけで編集できます。**
アプリのインストールもコマンド操作も必要ありません。

## 編集に参加するまで（初回のみ・約3分）

1. [GitHub](https://github.com/signup) で無料アカウントを作る
2. アカウントの二段階認証（2FA）を有効にする（GitHubの一律の必須設定ではありませんが、このwikiでは編集参加の条件としてお願いしています）
3. wiki管理者に GitHub のユーザー名を伝える
4. 管理者から届く招待メールの **Accept invitation** を押す

## ページを直す

1. 直したいページを開き、下のほうの **「このページをブラウザで編集する」** を押す
2. GitHubの編集画面が開くので、本文を書き換える
3. 右上の **Commit changes...** を押す
4. 変更内容のメモを一行書いて **Propose changes** を押す
5. 続けて出てくる **Create pull request** を押す

管理者が内容を確認して取り込むと、**1〜2分で本番サイトに反映**されます。

::: tip なぜ直接反映されないのか
編集はいったん「提案」として管理者に届き、確認を経てから公開されます。
誤編集や荒らしがそのまま公開されるのを防ぐための仕組みです。
急ぎの修正がある場合は管理者に直接連絡してください。
:::

## 過去の版に戻す

各ページの下に **「このページの変更履歴・復元」** があります。ここを押すと、そのページの全編集履歴が新しい順に並びます。

- 各行を押すと、**そのときに何がどう変わったか**が赤と緑の差分で表示されます
- 元に戻したい版を開き、右上の **⋯ → Revert** を押すと、その変更を取り消す提案が作られます（反映には管理者の承認が必要です）
- 特定の時点の内容を丸ごと見たいときは、**⋯ → View file** で当時のファイルが読めます

::: tip 失敗しても消えません
編集履歴はすべて残るので、消えて困るものはありません。元に戻す提案は誰でも作れます（反映は管理者が行います）。気軽に直してください。
:::

## 新しいページを作る

1. リポジトリの `docs/` フォルダを開く
2. **Add file → Create new file** を押す
3. ファイル名を `monsters/slime.md` のように入力（**必ず `.md` で終わらせる**）
4. 本文を書いて Commit → Propose changes

作ったあと、サイドバーに載せたい場合は管理者に伝えてください。

## アイテムのページを書く

アイテムは1品ごとにページがあります。[アイテム一覧](/items/)や武器・防具などの表で品名を押すと開きます。
多くはまだ名前だけなので、入手のしかた・使いみち・レシピなど、分かったことを自由に書いてください。
書き方は下の[書き方（Markdown）](#書き方-markdown)のとおりで、見出しも表も好きに使えます。
**ここに書いたものは、管理者の一括更新でも書き換わりません。**

モンスターが落とす品は、[ドロップ品から探す](/drops/)の逆引きページがその品のページです。こちらは末尾の「## 攻略メモ」に書いてください。

## MODの更新で増えたものを足す

モンスター・アイテム・呪文・職業などのページは、管理者がまとめて更新しています。
MODが更新されて新しいものが増えたときは、管理者を待たずに**手で足して構いません**。
ゲーム内で見える数字や文面を、そのまま写してください。

::: tip 残るもの・戻るもの
**足したもの**は、管理者の一括更新でも消えません。表に足した行、足した見出し（`##` `###`）とその本文、ページ末尾の「## 攻略メモ」、新しく作ったページ、すべて引き継がれます。

**もともとある行や文を書き換えたり消したりした分**は、一括更新で元に戻ります。直したいところがあれば[ご意見箱](/guide/feedback)か管理者へ。

手で足したものと同じ名前のものが正式に載ったら、正式なものに置き換わります。「攻略メモ」に書いたことはそのまま残ります。
:::

作ったページや行は、検索にはすぐ出ます。一覧の表には、管理者の一括更新で載ります。

### モンスター

ゲーム内の図鑑（DQMメニューの「モンスター図鑑」）に出る数字をそのまま写します。

1. `docs/monsters/` を開き、**Add file → Create new file** を押す
2. ファイル名は半角のローマ字で `docs/monsters/kingusuraimu.md` のように付ける（**必ず `.md`**）。正式なファイル名は管理者が付け直すので、読めれば何でも構いません
3. 下のひな形を貼り付けて、図鑑の数字に置き換える
4. 右上の **Commit changes...** → **Propose changes**

図鑑の欄との対応は次の通りです。

| ひな形の項目 | 図鑑の欄 |
| --- | --- |
| 系統 | 種族 |
| 活動時間 | 昼夜（昼のみ / 夜のみ / 昼夜） |
| 弱点 | 弱点（炎 / 氷 / 爆 / 風 / 強 / 無敵） |

- 出現場所は見かけた場所を書き、分からなければ「ランク3のふつうの土地」のままで大丈夫です
- [モンスター図鑑](/monsters/)の一覧にも載せたいときは、表の末尾に同じ形の行を1つ足します（No.は図鑑の番号）

### アイテム

[アイテム一覧](/items/)の「そのほか」の表に1行足します。分類は 素材 / 種 / 釣り / 特殊 / 建物 / 呪文 / 装飾 のどれかです（[素材一覧](/items/materials)のような分類ごとのページにも同じ品が並びますが、足すのは片方で構いません。一括更新で両方に載ります）。

```md
| 品名 | 素材 |
```

武器・防具・盾・アクセサリー・転生装備は、それぞれのページの表の末尾に1行足します。武器は武器種の見出し（剣・槍・杖…）の下の表へ。数値はゲーム内のツールチップの表示をそのまま、無い項目は `—` にします。

| ページ | 列の並び（左から） |
| --- | --- |
| 武器一覧・転生装備の武器 | 名前 / こうげき / 攻撃倍率 / 特殊効果 |
| 防具一覧 | 名前 / 部位 / しゅび / 魔法しゅび / そのほか / 特殊効果 |
| 盾一覧 | 名前 / しゅび / 魔法しゅび / 構え中 / 適正職業 / 特殊効果 |
| アクセサリー一覧 | 名前 / HP / MP / こうげき / しゅび / 魔法しゅび / まりょく / 特殊効果 |

```md
| 新しい剣 | 12 | ×2.55 | ドラゴン系に2倍 |
```

足した品のページは、管理者の一括更新で作られて品名がリンクになります。先に書きたいときは、`docs/items/` に `title: 品名` のページを作っておけば、そのままその品のページになります。

### 呪文・特技

[呪文一覧](/spells/)・[特技一覧](/skills/)の表の末尾に1行足します。値はゲーム内の「導きの書」のとおりに。

呪文の列は 名前 / 系統 / 消費MP / 威力 / 回復量 / 範囲、特技の列は 名前 / 武器 / 消費MP / 効果 / 習得 です。

```md
| 新しい呪文 | 炎 | 2 | 20 | — | 単体 |
| 新しい特技 | 短剣 | 6 | 効果の文 | 盗賊 Lv54 |
```

### 職業

[職業一覧](/jobs/)の「能力の伸び」と「武器の適性」の表に、それぞれ1行足します。ランクはゲーム内の職業表のとおりに（SSS〜E）。

能力の伸びの列は 職業 / HP / MP / こうげき / しゅび / まりょく / 魔法しゅび、武器の適性の列は 職業 / 剣 / 勇者の剣 / 槍 / 短剣 / 杖 / 棍 / 爪 / 拳 / ハンマー / 斧 / ムチ / 弓 / ブーメラン です。

```md
| 新しい職業 | S | E | S | S | E | E |
| 新しい職業 | A | B | S | B | E | B | A | B | A | SSS | B | C | B |
```

個別のページも作るなら、`docs/jobs/` にローマ字のファイル名で置き、他の職業のページ（たとえば[戦士](/jobs/senshi)）の **「このページをブラウザで編集する」** から中身を写して書き換えるのが早いです。「習得スキル」の表はゲーム内のスキル画面のとおりに。

### 遊び方ガイド

[遊び方ガイド](/play/)の各ページは、ゲーム内の「導きの書」の文面です。新しい項目が増えたら、当てはまる `##` の下に `### 項目名` と本文を足してください。新しい分類なら `## 分類名` から書き始めます。文面は導きの書のとおりに写します。

```md
### 新しい項目

導きの書の本文をそのまま。
```

description: DQMVIの「品名」を落とすモンスターの一覧。

### 出現場所

新しいバイオームは `docs/biomes/` にローマ字のファイル名でページを作り、`title` はゲーム内のバイオーム名そのままにします。中の表は[モンスター図鑑](/monsters/)と同じ並び（No. / モンスター / ランク / 系統 / 弱点 / 時間 / HP / こうげき / しゅび / EXP / G）です。[出現場所から探す](/biomes/)の表にも `| [名前](/biomes/ファイル名) | 5体 |` の形で1行足します。

### MOD更新履歴

[MOD更新履歴](/guide/updates)は公式サイトの原文を写したページです。新しい更新が出たら、いちばん新しい日付の `##` の上に同じ形で足します。文面は公式サイトの原文をそのまま、1項目1行で。

```md
## 2026.09.10

3項目

- **［追加］** 公式サイトの原文をそのまま
- **［変更］** 公式サイトの原文をそのまま
- **［修正］** 公式サイトの原文をそのまま
```

上の「更新の一覧」の表にも `| [2026.09.10](#_2026-09-10) | 3 | 1 | 1 | 1 |` の形で1行足すと、目次から飛べます。

## 書き方（Markdown）

覚えることは実質これだけです。

| やりたいこと | 書き方 |
| --- | --- |
| 見出し | `## 大見出し` / `### 小見出し` |
| 太字 | `**メタルスライム**` |
| リンク | `[はぐれメタル](/monsters/hagumeta)` |
| 箇条書き | 行頭に `- ` |
| 番号つき | 行頭に `1. ` |

### 表

```md
| モンスター | HP | EXP |
| --- | ---: | ---: |
| スライム | 8 | 5 |
| メタルスライム | 6 | 1350 |
```

`---:` にすると右寄せになります。数値の列は右寄せにしてください。

### 注意書きの枠

```md
::: tip 仲間にする条件
まもの使いのレベルを20以上にする必要があります。
:::

::: warning 注意
逃走率が高いため、先制できないとほぼ討伐できません。
:::
```

### ステータス枠

モンスターページで使う専用の枠です。`stats` と書いたコードブロックの中に「項目 | 値」を並べます。

````md
```stats
HP | 6
MP | 0
こうげき | 18
しゅび | 255 !
```
````

値のうしろに半角スペースと `!` を付けると、その数値が金色で強調されます。

## HTMLは書けません

セキュリティ上の理由で、本文に書いた **HTMLタグは無効**です。`<script>` や `<div>` はそのまま文字として表示されます。

これは、編集権限を持つ誰かのアカウントが乗っ取られたときに、サイトを見に来た人のブラウザで悪意あるスクリプトが動くことを防ぐためです。表・注記枠・ステータス枠は上記の記法で書けるので、通常の編集で困ることはありません。

同じ理由で、ページ冒頭の `---` で囲まれた部分（frontmatter）に書ける項目も限られています。`title` や `description` 以外を足すと検査で弾かれます。

どうしても表現できないものがある場合は、管理者に相談してください。

## 画像の入れ方

外部サイトの画像を直接読み込むことはできません。訪問者のIPアドレスが相手のサーバーに渡ってしまうためです。

画像は `docs/public/` にアップロードして、本文からは `![説明](/ファイル名.png)` の形で参照してください。置けるのは png / jpg / gif / webp などの画像だけです。

## 一度に大きく変えないでください

一度に大量のページや行を削除・移動するPRは、自動で止まるようになっています。カテゴリの整理など大きな変更をしたいときは、**先に管理者に相談**するか、小分けにして提案してください。

## 編集ルール

- **推測は推測と書く** — 未検証の情報には「未検証」と添える
- **バージョンを書く** — 仕様が変わることがあるため、確認したMODバージョンを明記する
- **他サイトからのコピペはしない** — 引用する場合は出典リンクを付ける
- **外部リンクは信頼できる先だけに** — 短縮URLや配布サイトの直リンクは避ける
- 迷ったら消さずに残す。判断は編集履歴で後から追える
