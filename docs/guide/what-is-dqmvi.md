# DQMVIとは

Minecraft向けのドラゴンクエストMOD「DQM」シリーズの最新版です。
バニラのMinecraftに、ドラクエのモンスター・職業・呪文・装備を追加します。

::: warning このページはテンプレートです
実際のMOD概要・作者情報・配布元リンクに書き換えてください。
:::

## 主な追加要素

| 要素 | 内容 |
| --- | --- |
| モンスター | スライム系・鳥系などが各バイオームにスポーン |
| 職業 | 戦士・僧侶などに転職し、熟練度で特技を習得 |
| 呪文・特技 | MPを消費して発動 |
| 装備・錬金 | ドロップ素材から武器防具を錬金 |
| なかまモンスター | 条件を満たすとモンスターが仲間になる |
