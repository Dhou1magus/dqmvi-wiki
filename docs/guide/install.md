# 導入方法

::: warning このページはテンプレートです
実際の手順に書き換えてください。
:::

## 1. 前提を用意する

1. Java をインストールする
2. MODローダーを導入する
3. 前提MODをダウンロードする

## 2. MODを入れる

1. DQMVI本体をダウンロードする
2. `mods` フォルダに入れる
3. Minecraftを起動する

::: tip modsフォルダの場所
Windows の場合は `%APPDATA%\.minecraft\mods` です。
エクスプローラーのアドレス欄にそのまま貼り付けると開けます。
:::

## つまずきやすいポイント

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 起動時にクラッシュする | 前提MODのバージョン違い | 対応バージョンを確認して入れ直す |
| モンスターが湧かない | 既に読み込み済みのチャンク | 新しい土地へ移動する |
| メモリ不足で落ちる | 割当メモリが少ない | ランチャーで割当を増やす |
