## 導入・マルチ {#setup}

### レシピはどこで見る？ レシピMODは要る？

タグ: JEI・レシピMOD・クラフトガイド・作り方・クラフトレシピ・鍛冶ポート・レシピ本・Just Enough Items

**武器・防具はほぼすべて「鍛冶用モンスターポート」で作ります。** 作業台のレシピではないので、JEIなどのレシピMODには出てきません。鍛冶ポートを開いたときの一覧が、実質のレシピ表です。

JEIで見えるのは作業台で作れるものだけです。入れておくと便利ではありますが、無くても困りません。

2026.08.30の更新で「**作業台のレシピを、鍛冶で作れるものは削除しました**」となりました。作業台で作れるものはさらに減っています。

→ [鍛冶のやりかた](/play/smithing) ／ [武器一覧](/items/weapons)

### フレンドとマルチで遊ぶには？

タグ: マルチ・サーバー・鯖・レンタルサーバー・e4mc・Aternos・Realms・友達と遊ぶ・パーティ・まるち・さーばー

方法は3つあります。

- **レンタルサーバーを借りる**
- **自分でサーバーを立てる**（後述の注意あり）
- **e4mc などのMODを使う** — ホストだけ入れれば動いたという報告があります

全員が**同じバージョンのDQMVI**を入れる必要があります。片方だけ更新すると入れません。

### 外部BGMが鳴らない

タグ: BGM・音楽・ogg・OGG Vorbis・外部BGM・曲が流れない・config/dqmvi/bgm

**短い曲は再生されない**という報告が出ています（不具合報告済み）。10分ほどの長さの曲だと鳴るようです。

そのほか確認されている点：

- ファイルは **OGG Vorbis** に変換する
- ファイル名の頭文字が大文字になっていないか
- MODを最新版にする

### マルチが重い

タグ: 重い・ラグ・カクつく・軽量化・メモリ・割り当て・サーバースペック・影MOD・処理落ち・おもい・らぐ

5人で16GBのメモリなら足りているという報告が多いです。重さの原因として挙がっているのは次のものです。

- 拠点にペットを出しすぎている
- 誰かが遠出してチャンクを読み込んでいる
- 影MODを入れている
- **踏破済みのダンジョンを撤去していない**（仕掛けとモンスターが多いため）

### サーバーを立てたのにDQMバイオームが出てこない

タグ: DQMバイオーム・生成されない・見つからない・サーバー・server.jar・worldフォルダ・ワールド生成

**MODを入れる前にワールドを生成してしまったのが原因**です。MODなしで最初に作られたワールドには「バニラのバイオームだけ生成する」という設定が書き込まれ、あとからMODを入れても追記されません。

正しい順番はこちらです。

1. `server.jar` を起動する
2. `eula.txt` を書き換える
3. もう一度 `server.jar` を起動して、閉じる
4. **`world` フォルダを削除する**
5. `mods` にDQMVIを入れる
6. サーバーを起動する

`world` フォルダを消すとワールドのデータも消えます。作り直しになる点にご注意ください。

## モンスター {#monsters}

### モンスターが湧かない

タグ: 湧かない・沸かない・スポーン・湧き潰し・ニフラムブロック・湧き上限・抽選回数・開始5分・わかない・わきつぶし

挙がっている原因はこちらです。

- 湧き潰しをしている（松明などで湧かなくなります）
- **ニフラムブロック**の効果範囲に入っている
- 湧き上限に達している（水中の魚を倒していないと埋まることがあります）
- DQM設定のスポーン範囲・抽選回数の設定

安全な小部屋の中にいると湧かず、外に出た瞬間に大量に湧く、という報告があります。

### 肉はいつ倒せばいい？ 食べ終わるのを待つ？

タグ: 肉・くんせいにく・ほねつきにく・しもふりにく・霜降り肉・仲間にする・スカウト・テイム・勧誘・えさ・ハート・にく・なかまにする

**食べている間に倒します。食べ終わるまで待つ必要はありません。**

「食べ終わってハートが出てから」と言われることもありますが、導きの書の記述はこちらです。

| 肉 | 仲間になりやすさ |
| --- | ---: |
| くんせいにく | +4% |
| ほねつきにく | +8% |
| しもふりにく | +16% |

**転生系・魔王系・ボスオーラ付きは肉を食べません。** それ以外はメタル系も食べます。肉は鍛冶で作れます。

### メタル系はどうやって倒す？

タグ: メタル・はぐれメタル・メタルキング・どくばり・まじんのかなづち・会心・逃げる・メタル狩り・めたる・はぐれめたる

**まじんのかなづち**が有力です。2026.08.29の更新で「まじんのかなづちの『ミスか会心』が、**メタル系にも効くようになりました**」となりました。

魔神斬り・大まじん斬り・一閃突きがメタル系に効かない不具合も、2026.08.21に直っています。逃げられる前に、会心が出る武器で一撃を狙うのが基本です。

魔法戦士のだいまじん斬り、道具使いの一閃突きなども挙がっています。

メタル系は呪文が効きません。

→ [メタル系の一覧](/species/metal)

## 仲間・ペット {#pets}

### 「空の証」「地上の証」が使えるモンスターが分からない

タグ: 騎乗・乗れる・ライド・空の証・地上の証・海の証・騎乗の証・乗り方・飛べる・ガルーダ・きじょう・のれる・そらのあかし

**名前の横に【空】【地上】【海】と書いてあるモンスターにだけ**使えます。書いていない子には効きません。空はヘルコンドル系（ガルーダ・ごくらくちょう・ほうおうなど）が該当します。

証を付けると、大きな仲間の背に乗って旅ができます。

転生させると証が外れてしまうことがあります。乗れなくなったら付け直してみてください。

### 仲間モンスターのレベル上げはどうする？

タグ: レベリング・レベル上げ・経験値稼ぎ・育成・天空TT・トラップタワー・防衛ポート・ボート・低レベル・てんくうTT・れべるあげ・けいけんち

高いところに湧き場を作るやり方が主流です。

- **モンスターポート（防衛用）**に強い仲間を入れて狩らせ、育てたい子は**ボートに乗せて**動かないようにしておく
- 矢印ブロックで湧き場を作り、育てたい子を**追従**にしてボートに詰め、遠距離職でちくちく倒す

**待機状態の仲間には経験値が入りません。** プレイヤーから離れすぎても入りません（64マスという報告があります）。

防衛ポートのペットが倒した相手は**仲間になりません**。経験値は入りますが、ゴールドは入りません。

### 仲間に経験値が入らない

タグ: 経験値・EXP・分配・共有・待機・64マス・レベル差・パーティ経験値・けいけんち・たいき

入らない条件が3つあります。

- **待機状態**になっている
- プレイヤーから**離れすぎている**。2026.08.27の更新で「ペットへの経験値の配分を、**同じチャンクから64マス以内**に変えました」となりました
- 味方プレイヤーのペットには入らない

防衛ポートに入れた仲間には経験値が入ります（ゴールドは入りません）。

### ポートやベル、ホームを失くした

タグ: 紛失・ロスト・なくした・作り方・モンスターポート・ペット収納ベル・ホーム・復元・再入手・骨・丸石・なくした・ふんしつ

作り直せます。

| 失くしたもの | 作り方 |
| --- | --- |
| モンスターポート（拠点用） | 作業台で、骨を丸石8個で囲む |
| モンスターポート（鍛冶用） | 作業台で、鉄インゴットを丸石8個で囲む |
| ホーム・その他のポート | 鍛冶用ポートの「その他」から作る |
| 配合の杖 | 鍛冶用ポートで いのちの石×8＋かしの杖 |
| ペット収納ベル | 鍛冶で「ペット収納ベル（復元）」を作る |

まず鍛冶用ポートさえ作れれば、たいていのものは作り直せます。

**ベルは中身ごと取り戻せます。** 2026.08.17の更新で「ペット収納ベルをなくしても、鍛冶で『ペット収納ベル（復元）』を作れば中身を取り戻せる」ようになりました。なくしたベルが新しい順に並び、匹数と顔ぶれを見て選べます。

### ペットをお気に入り登録したい

タグ: お気に入り・★・星マーク・Shift+右クリック・ペット収納ベル・マーキング・おきにいり

ペット収納ベルを開き、対象のモンスターに **Shift + 右クリック**で★が付きます。ベルの中で操作するのがポイントです。

## 配合・転生 {#breeding}

### 配合表はある？ 子どもは選べる？

タグ: 配合・配合表・配合レシピ・組み合わせ・特殊配合・4体配合・子ども・候補・配合の杖・配合の神官・はいごう・はいごうひょう

**「AとBを配合するとC」という固定の表はありません。** 生まれる子は候補の中から確率で決まります。4体配合や特殊配合も見つかっていません。

**配合の杖**なら Lv20以上の仲間2匹から。**配合の神官**なら Minecraft経験値レベル10以上で、収納ベルの中の2匹をペットのレベル不問で選べます（成功後にレベル10を消費）。

候補に転生モンスターが出ることがあり、その確率は約10%という報告があります。ランクが上がるのは低確率なので、上がったら儲けものくらいに考えるのがよさそうです。

→ [ペットと配合](/play/pets)

### 名前の「＋1」って何？

タグ: ＋値・プラス値・プラス・+1・世代・血統・継承・上限・ぷらす・せだい

**配合・転生を重ねた世代数**です。子は両親のうち大きいほうの数字＋1になります。

**＋1ごとに、装備と種バフを除いた基準能力の継承が約10%ずつ強くなります。＋10でおよそ2倍。上限はありません。**

つまり＋の数字が大きい子ほど、親の強さをしっかり受け継ぎます。

2026.08.29の更新で「配合のプラス値を、**両親の合計レベル**で変更するようにしました」となりました。以前のように必ず＋1ずつ増えるとは限りません。

### お見合い配合（他の人のペットと配合）のやり方

タグ: お見合い・Shift+0・他人のペット・別のプレイヤーの仲間・マルチ配合・おみあい・おみあいはいごう

手順が独特で、**出す側の操作**が要ります。

1. 両方のプレイヤーがDQM設定で**お見合いを許可**する
2. **出す側**がペットを右クリックして詳細メニューを開き、そのまま **Shift + 0**（テンキーではないほうの0）を押す → 60秒間のお見合い待機状態になる
3. その間に、もう一方が**配合の杖**で選ぶ

「このペットは別のプレイヤーの仲間です」と出る場合は、手順2ができていません。

お見合いで生まれた子ども同士を、もう一度お見合いさせることはできません。片方は野生の個体か、通常の配合で生まれた子である必要があります。

### 配合と転生、どっちがいい？

タグ: 転生・転生の杖・配合・見た目・強化・どっちが強い・てんせい・はいごう

**転生**は、親Aの見た目のまま生まれ変わらせる仕組みです（転生の杖・Lv20以上の2匹）。見た目を変えたくないときに使います。

どちらも＋値が1つ増えるので、強くすること自体はどちらでもできます。強い子を作るなら、レベルを上げてから配合するより、**先に＋値を稼いでから育てるほうが効率がいい**という意見が多いです。

### 配合でランクを上げるコツは？

タグ: 配合ランク・ランクアップ・+2・確率・両親のレベル

ランクが上がるのは低確率です（5%という声があります）。**両親のレベルが高いほうが上がりやすい**という報告はありますが、条件ははっきりしていません。

配合を重ねるほど、高ランクのモンスターに手が届くようになります。

### 配合の杖・配合の神官で選べない

タグ: 配合の杖・配合の神官・反応しない・選べない・右クリック判定・ペットクリック判定・Nキー・Bキー

**ペットの右クリック判定がOFF**になっていると選べません。デフォルトは **N キー**、またはZキーのメニューから切り替えられます。これで直った報告が多数あります。

配合の神官のUIがはみ出て見えないときは、マイクラのGUIの大きさを1段階下げるか、フルスクリーンにしてみてください。

## 職業・スキル {#jobs}

### 職業の証はどこで手に入る？

タグ: 職業の証・戦士の証・バトルマスターの証・賢者の証・勇者の証・転職・上級職・金の宝箱・サブ職業の証・あかし・てんしょく

**金の宝箱**から出ます。**宝箱のランクが高いほど、強い職業の証**が出るようになっています。

上級職は前提となる職業レベルも要ります（例：バトルマスター＝戦士30と武闘家30、勇者＝バトルマスター30か賢者30）。条件は導きの書のアイテム欄に載っています。

→ [職業一覧](/jobs/)

### サブ職業のレベルが上がらない

タグ: サブ職業・サブ職・サブジョブ・レベルが上がらない・メインの半分・ダーマ神殿・さぶしょく・さぶしょくぎょう

サブ職業の力は、**「サブで育てたレベル」と「メインのレベルの半分」の低いほう**になります。

**その職業を一度もメインで育てていないと0**で、何も上乗せされません。まずはその職業をメインにして育ててください。

例：メイン魔法使いLv200・サブ遊び人Lv101 → メインの半分の100が上限なので、遊び人Lv100ぶん。

武器や盾の適正、特技の職業条件、呪文の効果時間は、**メインとサブで良いほう**が使われます。

### SP（スキルポイント）はどうやって増やす？

タグ: SP・スキルポイント・パッシブ・パッシブスキル・スキル振り・34

**レベルアップで増えるようだ**という見立てが出ていますが、確かめられていません。上限が34から動かないという報告もあります。

はっきりした条件が分かった方は[ご意見箱](/guide/feedback)から教えてください。

## アイテム・鍛冶・農業 {#items}

### 小さなメダル・福引券はどこで使う？

タグ: ちいさなメダル・小さなメダル・メダル王・福引・福引券・ふくびき券・福引屋・交換所・めだる・ふくびき

**小さなメダル**は「メダル王の城」を建てると、交換所で景品に換えられます。

**福引券**は福引屋の施設で使います。福引屋の施設アイテムは金の宝箱から出ますが、なかなか出ないという声が多く、見たことがないという報告も複数あります。

### 鍛冶レベルの上げ方

タグ: 鍛冶レベル・鍛治レベル・作業レベル・熟練レベル・鍛冶Lv・鍛冶ポート・得意作業・かじれべる・かじ

**ペットのレベルを上げる**か、**ポートにたくさん入れる**かのどちらかです。

似た名前の2つがあります。

- **鍛冶レベル** … モンスターのレベルが上がるときに、ランダムで一緒に上がります
- **熟練レベル** … 鍛冶の作業回数をこなすと上がります

鍛冶ポートの左上に出る「鍛冶Lv」は、**ポートに入れているモンスターの合計**です。1体の上限が低くても、たくさん入れれば合計は伸びます。

得意作業（鍛冶・農業・建築）が一致していると、レベルアップのときにその作業レベルが伸びやすいようです。

→ [鍛冶のやりかた](/play/smithing)

### 種や苗はかまどで焼いて増やせる？

タグ: 種・苗・かまど・焼く・薬草・超・極・品質・交配種・剛力の種・叡智の種

**今作では焼いて苗にはできません。** 過去作にあった仕組みですが無くなりました。

種も実も畑で育てて増やします。品質は 無印 → 超 → 極 の3段階（黄金だけ真・極まで4段階）で、上の品質ほど効果が大きくなります。違う系統の作物を隣どうしで育てると、まれに交配種（剛力の種・叡智の種）が採れます。

→ [農業](/play/farming)

### 「貴重なレシピ」はどこで手に入る？

タグ: 貴重なレシピ・釣り・魚交換所・30000ポイント・魚ポイント

**釣りの魚交換所**で交換できます。1つ30,000ポイントと高額です。

種類は 剣・短剣／斧・槌・棍／槍・鞭・爪／弓・ブーメラン／魔法／防具／竜・炎／メタル・氷／魔・呪／破壊／伝説／天空 の12種です。

魚交換所の施設アイテムは金の宝箱から出ます。

→ [釣り](/play/fishing)

### MOD追加の鉄鉱石が焼けない

タグ: 鉄鉱石・鉱石・焼けない・精錬・かまど・溶鉱炉・磨き砂

**2026.08.31の更新で「精錬レシピ27件の修正」が入っています。** まずはMODを最新版にしてみてください。

それ以前は、かまどでも溶鉱炉でも反応しないという報告が相次いでいました（プラチナの原石とバニラの鉄鉱石は焼けたという報告もあります）。最新版でも焼けないなら、公式Discordの不具合報告へどうぞ。

→ [MOD更新履歴](/guide/updates)

### 武器は修理できる？

タグ: 修理・耐久・耐久0・壊れる・打ち直し・修理キット・杖・しゅうり・たいきゅう

**できます。** 2026.08.29の更新で「装備は耐久0でも壊れず、性能だけ下がるようにしました。**修理すれば元に戻ります**」となりました。耐久が尽きても装備が消えることはありません。

杖が打ち直しできないという報告もありましたが、こちらも2026.08.19に「杖も打ち直しできるように修正」されています。

できた装備は打ち直しで+1〜+9まで強化できます。後半は成功率が下がりますが、性能の伸びは大きくなります。

→ [MOD更新履歴](/guide/updates)

## バイオーム・施設 {#biomes}

### バイオームランクはどうやって上げる？

タグ: ランク上げ・ランクアップ・ランク5・ランク6・ランク7・見つからない・バイオームランク統一・同種バイオーム昇格・エリアランク・フィールドレベル・らんく・らんくあげ

ランクは、**そのバイオームを何番目に見つけたか**で決まります。新しい土地を見つけるほど、その後に見つかる場所のランクが高くなります。

**すでに見つけた場所のランクは後から上がりません。** ランクを上げたければ、まだ行っていない土地をひたすら探すのが唯一の方法です。画面のバイオーム名の横に「(ランク1)」と出ます。

マルチで人によってランクが違うのは、見つけた数が人ごとに違うためです。DQM設定の**バイオームランク統一**をONにすると、一番進んでいる人に合わせられます。

**同種バイオーム昇格**をONにすると、拠点の平原がいきなりランク3になって手が出せなくなることがあります。OFFに戻せばすぐ元に戻ります。

どのモンスターが何ランクの土地に湧くかは、[モンスター図鑑](/monsters/)の「ランク」列で分かります（図鑑画面の「ランク」と同じ数字です）。

### 踏破したダンジョンは撤去したほうがいい？

タグ: ダンジョン撤去・撤去・削除・踏破済み・Zメニュー・重い

そのダンジョンの近くに寄ったときに**重いと感じるなら撤去**してください。重くないならそのままで構いません。仕掛けとモンスターが多いぶん負荷になります。

**まだ答えが分かっていない項目もあります。** 解決した方は[ご意見箱](/guide/feedback)から教えていただけると助かります。
