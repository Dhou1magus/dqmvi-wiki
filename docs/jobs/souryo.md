# 僧侶

回復・蘇生・状態回復とバギ系を得意とする支援職。MPと魔守備が高い。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 魔法メニューから味方を選んで回復・蘇生・補助を行う。戦闘前後にMPを確保しておく。 |
| 武器の補正 | 最高 槍・竪琴=S（×1.20） / 最低 勇者の剣・爪・拳・銃・戦輪・大鎌・戦籠手=E（×0.30） |
| 魔法の補正 | バギ・回復蘇生・ホイミ・全体回復・再生・蘇生・補助・状態回復×1.2、弱体×1.0、メラ・ギラ・イオ・デイン・ドルマ・ヒャド・その他攻撃×0.7、魔法剣×0.3。 |
| 必殺技 | Lv200 聖者の詩（まわりの倒れた仲間を全員よみがえらせ、HPも回復する） / Lv300 神域の加護（まわりの仲間全員のHPを回復し、女神の祝福(一度だけ致命傷を防ぐ)をかける（効果60秒）） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 初期職のため条件なし。 |
| その他 | 聖者の詩は周囲の倒れた仲間を蘇生。神域の加護は全体回復と一度だけ致命傷を防ぐ効果。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | B
MP | S !
こうげき | B
しゅび | D
まりょく | S !
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
