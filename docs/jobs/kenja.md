# 賢者

MP・まりょくがよく伸びます。杖が得意です。

## 能力の伸び

```stats
HP | B
MP | S !
こうげき | B
しゅび | D
まりょく | S !
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
