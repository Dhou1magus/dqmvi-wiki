# 賢者

魔法使いと僧侶の呪文を広く扱う万能魔法職。ドルマ系が最も得意。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 攻撃・回復・補助を、状況に合わせて魔法メニューから切り替える。専門職より倍率が低い点に注意。 |
| 武器の補正 | 最高 杖=S（×1.20） / 最低 勇者の剣・爪・斧・戦輪・大鎌・戦籠手・ドリル・鎖鎌=E（×0.30） |
| 魔法の補正 | ドルマ×1.2、メラ・ギラ・イオ・デイン・バギ・ヒャド・その他攻撃・回復蘇生・ホイミ・全体回復・再生・蘇生・補助・状態回復・弱体×1.0、魔法剣×0.3。 |
| 必殺技 | Lv200 神の息吹（30秒間、呪文の威力と詠唱の速さが上がる） / Lv300 天恵の光（まわりの仲間全員を回復し、60秒間 最大HPを+100する） |
| サブ職業のとき | サブが賢者：魔法使い・僧侶・賢者の習得呪文を実効Lvまで使える。賢者経由の呪文は威力75%。 |
| 転職条件 | 魔法使いLv30＋僧侶Lv30。 |
| その他 | 強みは対応できる幅の広さ。1系統だけの最大倍率は、魔法使い・僧侶のほうが上。賢者経由の魔法・特技は威力75%。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | B
MP | S !
こうげき | B
しゅび | D
まりょく | S !
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
