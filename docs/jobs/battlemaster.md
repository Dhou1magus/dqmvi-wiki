# バトルマスター

最高クラスの物理火力と多彩な近接特技を持つ上級前衛。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 拳・爪・槍など適正の高い武器で接近し、まわしげり・正拳突き・ムーンサルト・ミラクルムーン・しんくうは・捨て身・爆裂拳・せいけん爆撃を状況で使い分ける。テンションや連撃必殺技を強敵へ重ねる。 |
| 武器の補正 | 最高 拳=SSS（×1.50） / 最低 杖・竪琴=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 テンションブースト（テンションが一気に4段階上がる（効果30秒）） / Lv300 ラッシュバーン（対象と周囲へランダムに4回攻撃する(二刀流なら5回)） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 戦士Lv30＋武闘家Lv30。 |
| その他 | 魔法面は弱い。ラッシュバーンは忍者の二刀流中なら攻撃回数が4回から5回になる。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | S !
MP | D
こうげき | S !
しゅび | B
まりょく | E
魔法しゅび | E
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
