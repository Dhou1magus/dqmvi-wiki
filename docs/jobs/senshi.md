# 戦士

HP・攻撃・守備が高い前衛。剣・槍・斧で正面から戦う。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 敵へ接近して通常攻撃と特技を使う。斧: 大木斬・かぶとわり・オノむそう・蒼天魔斬・鉄甲斬・烈風獣神斬。剣: 火炎斬り・氷結斬り・真空斬り・爆裂斬り(属性斬り)。会心必中系の必殺技は強敵へ集中して使う。 |
| 武器の補正 | 最高 斧=SSS（×1.50） / 最低 杖・竪琴=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 会心必中（15秒間、通常攻撃がかならず会心になる） / Lv300 戦陣の凱歌（攻撃力と守備力が2段階上がり、20秒間すべての攻撃が会心になる） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 初期職のため条件なし。 |
| その他 | MP・魔力・魔守備は低い。物理攻撃と耐久を伸ばしたいサブ職にも向く。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | S !
MP | E
こうげき | S !
しゅび | S !
まりょく | E
魔法しゅび | E
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
