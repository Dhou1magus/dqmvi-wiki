# スーパースター

短剣・棍・ムチが得意です。

## 能力の伸び

```stats
HP | A
MP | C
こうげき | B
しゅび | C
まりょく | B
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
