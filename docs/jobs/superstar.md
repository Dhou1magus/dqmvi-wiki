# スーパースター

ムチ・棍・短剣を使う支援型。能力は平均的で、妨害と自己強化に優れる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 足ばらい・天地のかまえ・黄泉送り・なぎはらい・氷結らんげき・断空なぎはらい・ドラムクラッシュ・ゴールドハンマーで敵を崩し、必殺技で被弾時マヒや高速チャージを狙う。 |
| 武器の補正 | 最高 棍=SSS（×1.50） / 最低 勇者の剣・斧・大鎌=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 モンスターゾーン（30秒間、自分を攻撃してきた敵をマヒさせる） / Lv300 銀幕の世界（25秒間、チャージが1秒になり、攻撃力と呪文威力が2段階上がる） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 遊び人Lv30＋武闘家Lv30。 |
| その他 | 銀幕の世界は25秒間チャージ1秒、攻撃力と呪文威力を2段階上げる。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | C
こうげき | B
しゅび | C
まりょく | B
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
