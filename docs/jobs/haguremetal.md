# はぐれメタル

HPは極端に低いが、MP・守備・魔守備・魔力が非常に高い特殊職。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 高い耐久補正と息特技(灼熱・輝く息は待ち3秒、煉獄火炎・絶対零度は待ち5秒)や呪文を使う。HPそのものは低いため固定級の大ダメージに注意。 |
| 武器の補正 | 最高 杖=SS（×1.35） / 最低 剣・勇者の剣=E（×0.30） |
| 魔法の補正 | 全系統×1.0。 |
| 必殺技 | Lv200 メタルボディ（30秒間、受けるダメージが最大2になる） / Lv300 マダンテ（MPを全部使い切って、使った量に比例した特大ダメージ） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 勇者Lv30＋スーパースターLv30。 |
| その他 | メタルボディは30秒間被ダメージ最大2。マダンテは全MP比例の特大攻撃。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | E
MP | S !
こうげき | D
しゅび | SS !
まりょく | S !
魔法しゅび | S !
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **2種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| メタルキングの盾 | ×1.42 | ×1.42 | ×3 |
| スライムトレイ | ×1.04 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
