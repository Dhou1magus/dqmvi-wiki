# 職業について
 職業毎に様々な特技・呪文を覚えることができます
一部の職業は専用の証を入手し、前提となる職業のレベルを上げた後、ダーマ神殿で転職を行う必要があります。

## 証の入手
ダンジョンの金宝箱もしくは超マスターエッグを倒すと手に入ります
超マスターエッグは、ダンジョンで稀に出現します
ボスが出現するときにお供として出てきやすいです

### 入手場所一覧(検証予定)
作成中

## 転職の仕方
[ダーマ神殿](/items/sdama)を建築した後、ダーマ神官に話しかけて転職することができます


## サブ職業 {#subjob-rules}
サブ○○の証を入手すると対応した職業をサブに設定することができます
サブ職業を設定すると、そのLv相分のステータスが加算されます
もちろん、そのレベルまでの習得呪文・特技も使用できるようになります
盗賊や魔物使いなどのパッシブ効果も発動します
- サブ職業のLvは「この職の育成済みLv」と「現在のメイン職Lv÷2」のうち低い方が使用されます
- 武器・盾・魔法の補正は、メインとサブのうち良い方が使用されます
- サブ職業には経験値が入りません。レベルを上げたいときはメイン職業に設定しましょう
