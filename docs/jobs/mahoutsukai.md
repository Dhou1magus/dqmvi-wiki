# 魔法使い

MP・まりょくがよく伸びます。杖・棍が得意です。

## 能力の伸び

```stats
HP | C
MP | S !
こうげき | C
しゅび | D
まりょく | S !
魔法しゅび | B
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
