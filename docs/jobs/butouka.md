# 武闘家

高いHP・攻撃と会心率を生かす近接アタッカー。爪・拳が得意。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 爪か拳を装備して、近距離で戦う。特技：裂鋼拳・ためる・ウィングブロウ・必中拳・タイガークロー・ゴッドスマッシュ・ゴールドフィンガー・ライガークラッシュ。守備は戦士より低いので、攻撃を受ける位置に注意。 |
| 武器の補正 | 最高 爪=SSS（×1.50） / 最低 勇者の剣・杖・ブーメラン・銃・竪琴=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 一喝（まわりの敵全体をスタンさせ、同時にダメージを与える） / Lv300 崩命拳（敵1体に攻撃力に応じた大ダメージ） |
| サブ職業のとき | この職だけの常時パッシブはない（共通の能力加算・習得技・良い方の適正だけが有効）。 |
| 転職条件 | 初期職のため条件なし。 |
| その他 | 職業スキルに会心率アップが複数ある。能力アップはセットしたときだけ加算される。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | S !
MP | E
こうげき | S !
しゅび | B
まりょく | E

```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
