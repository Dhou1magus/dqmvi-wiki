# 戦輪士

戦輪を投げ、まだ当たっていない敵へ次々に跳ね返して集団を削る遠距離物理職。単体への初撃は標準火力。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 戦輪を持って左クリック長押しし、光ったら離して投げる。命中後は近くの未命中敵へ自動で跳弾する。特技(Lv20双輪斬・54風裂輪・78旋回結界・102影縫い輪・126追命輪・150八方輪舞)で同時に投げた戦輪は1本ずつ自分で敵を探して跳弾する。 |
| 武器の補正 | 最高 戦輪=SSS（×1.50） / 最低 バニラ剣・勇者の剣・杖=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 輪舞乱閃（周囲の敵へ戦輪の残像を放ち、一斉に切り刻む） / Lv300 神輪廻天（60秒間、戦輪の跳弾上限を2回増やし、跳弾の威力低下を無くす） |
| サブ職業のとき | 戦輪の跳弾数強化はサブでも実効Lv基準で有効。戦輪以外へは跳弾効果を付けない。 |
| 転職条件 | 盗賊Lv30＋レンジャーLv30。 |
| その他 | 戦輪自体は2〜5回跳弾し、1回ごとに威力15%低下。Lv30/120/210で跳弾上限+1、Lv300必殺中はさらに+2・減衰なし。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。
