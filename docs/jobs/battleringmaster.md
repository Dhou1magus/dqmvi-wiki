# 戦輪士

戦輪を投げ、まだ当たっていない敵へ次々に跳ね返して集団を削る遠距離物理職。単体への最初の一撃は、標準的な火力。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 戦輪を持って左クリック長押し、光ったら離して投げる。当たったあとは、近くのまだ当たっていない敵へ自動で跳弾する。特技：Lv20 双輪斬／54 風裂輪／78 旋回結界／102 影縫い輪／126 追命輪／150 八方輪舞。特技で同時に投げた戦輪は、1本ずつ自分で敵を探して跳弾する。 |
| 武器の補正 | 最高 戦輪=SSS（×1.50） / 最低 バニラ剣・勇者の剣・杖=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 輪舞乱閃（周囲の敵へ戦輪の残像を放ち、一斉に切り刻む） / Lv300 神輪廻天（60秒間、戦輪の跳弾上限を2回増やし、跳弾の威力低下を無くす） |
| サブ職業のとき | サブが戦輪士：跳弾は実効Lvで増える（最大5回）。メインもサブも戦輪士でない：跳弾は2回で固定。戦輪以外の武器には跳弾が付かない。 |
| 転職条件 | 盗賊Lv30＋レンジャーLv30。 |
| その他 | 跳弾回数（メイン時）：Lv1で2回／40で3回／80で4回／120で5回／160で6回／200で7回／250で8回／300で9回。当たる回数＝最初の1発＋跳弾回数。跳弾1回ごとに威力15%低下。戦輪の最終威力は、どの職業でも0.2倍。Lv300の必殺技中：跳弾+2回・威力の低下なし。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
