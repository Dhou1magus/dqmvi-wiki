# 道具マスター

槍が得意な上級職。習得Lvに応じて、使ったアイテムの効果が最大4倍になる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 回復・補助アイテムを手元に用意し、状況に合わせて使う。倍率技（Lv20/90/150でアイテム効果2/3/4倍）は、覚えれば自動で効く。 |
| 武器の補正 | 最高 槍=SSS（×1.50） / 最低 杖=D（×0.70） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 強化ガジェット零式II（30秒間、その中で与えるダメージが3倍になる魔法陣を置く(零式Iの強化版)） / Lv300 アブソリュートレイII（敵1体にダメージを与え、呪文耐性と守備力を3段階下げる(レイIの強化版)） |
| サブ職業のとき | サブが道具マスター：実効Lv20/90/150でアイテム効果2/3/4倍。サブでも習得の判定に入る。 |
| 転職条件 | 道具使いLv30＋魔物使いLv30。 |
| その他 | 覚えている中で一番高い倍率だけを使う（重ねがけしない）。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。
