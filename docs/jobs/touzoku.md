# 盗賊

短剣中心の素早い物理職。状態異常連携と追加の盗み抽選を持つ。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | ヴァイパーファング・ヒュプノスハント・バンパイアエッジ・タナトスハント・アサシンアタック・カオスエッジ・ナイトメアファングで毒・眠り等を付け、対応する追撃技を使う。通常モンスターを倒すと盗み抽選が行われる。 |
| 武器の補正 | 最高 短剣=SSS（×1.50） / 最低 勇者の剣・杖・棍・ハンマー・竪琴=D（×0.70） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 お宝ハンター（まわりの敵をショックさせ、同時にアイテムを盗む） / Lv300 ファントムハック（対象と周囲の敵全員にダメージを与え、ショックさせる） |
| サブ職業のとき | 盗み抽選はサブでも有効。通常・レア・超レア枠を30%・10%・3%で個別抽選する。 |
| 転職条件 | 遊び人Lv30＋戦士Lv30。 |
| その他 | 転生・魔王・ボス系は盗み対象外。お宝ハンターは周囲の敵をショックさせて盗む。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | E
こうげき | A
しゅび | C
まりょく | E
魔法しゅび | E
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
