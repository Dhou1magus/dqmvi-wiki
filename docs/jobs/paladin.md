# パラディン

全職最高クラスのHP・守備を持つ盾役。再生・回復補助も扱える。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 盾と防具を整えて敵の前に立ち、やいばのぼうぎょ・大防御で受け、ゴールドラッシュ・ランドインパクト・プレートインパクト・デビルクラッシュで反撃する。無敵必殺技で攻撃を受け止める。 |
| 武器の補正 | 最高 ハンマー=SSS（×1.50） / 最低 短剣・爪・ムチ・ブーメラン・戦輪=D（×0.70） |
| 魔法の補正 | 回復蘇生・ホイミ・全体回復・再生・蘇生・補助・状態回復×1.0、その他×0.3。 |
| 必殺技 | Lv200 パラディンガード（12秒間、受けるダメージが0になる） / Lv300 聖光の鎧（60秒間、自分の最大HPが2倍になる） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 僧侶Lv30＋武闘家Lv30。 |
| その他 | パラディンガードは12秒間被ダメージ0。聖光の鎧は60秒間最大HP2倍。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | S !
MP | C
こうげき | S !
しゅび | S !
まりょく | B
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
