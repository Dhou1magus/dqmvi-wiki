# ゴーストマスター

倒した敵を確率で一時的な亡霊ペットに変え、大鎌で魂を溜めて数で押す召喚職。亡霊は黒い炎をまとう。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 本人か通常ペットで敵を倒して、亡霊化を狙う。死霊召喚I〜VII（Lv30/52/63/85/106/128/150）：指定ランクの、図鑑で討伐済みの通常種を60秒召喚。大鎌の特技：Lv20 魂刈り（1.6倍・与ダメージの1/10をHP回復）／41 亡者の波動（全方位5マスの闇魔法）／74 呪縛の鎌（1.8倍・50%で麻痺）。大鎌の特技：Lv95 魂魄吸収（2倍・与ダメージの1/10をMP回復）／117 死霊爆破（召喚中の死霊1体を爆発）／139 冥界大鎌（全方位5マス・2.5倍）。 |
| 武器の補正 | 最高 杖・大鎌=SSS（×1.50） / 最低 勇者の剣・弓・ブーメラン・銃・戦輪・戦籠手=E（×0.30） |
| 魔法の補正 | ドルマ×1.0、その他×0.3。 |
| 必殺技 | Lv200 死者の軍勢（最近倒した8体を亡霊として30秒召喚する） / Lv300 魂の解放（場の亡霊を爆発させ、1体につき最大HP10%を回復する） |
| サブ職業のとき | サブでも実効Lv基準で有効：亡霊化・確率・能力の割合・持続時間・最大数・死霊召喚・大鎌の魂の蓄積。 |
| 転職条件 | 賢者Lv30＋魔物使いLv30。 |
| その他 | 亡霊化：確率20〜30%／能力40〜75%／持続30〜60秒／最大2〜4体。大鎌で倒すほど魂が溜まり、魂300で攻撃+30%（ゴーストマスターは実効Lv90/180/270で最大+40%/+50%/+60%）。死霊召喚：今いる場所の自然湧きLv・図鑑能力100%で召喚する。亡霊はベル・預かり所に入れられず、配合・転生・お見合いにも使えない。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
