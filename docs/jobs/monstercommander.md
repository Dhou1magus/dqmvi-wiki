# モンスターロード

本人の与ダメージを0にし、ペットの全能力・耐久を大きく伸ばす指揮専業職。標的・連携・号令・応援・旗の「指揮」でペットを動かし続ける。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 攻撃はペットへ任せ、作戦・対象・必殺技で指揮する。本人が殴ってもダメージは与えられない。集中攻撃命令(Lv20)はMP5で、視線上128マス先の敵まで指定でき、命じたペットは30秒間 攻撃+20%。防御陣形(54)・癒しの号令(78)・奮起の号令(102)・緊急招集(126)・王者の号令(150)。左クリック長押しで攻撃の号令、しゃがみ長押しで守りの号令。ペットが攻撃する直前に合図キーで連携。 |
| 武器の補正 | 全武器 E（与ダメ×0.30） |
| 魔法の補正 | 回復蘇生・ホイミ・全体回復・再生・蘇生・状態回復×1.0、その他×0.3。 |
| 必殺技 | Lv300 総攻撃指令（ペット全員の次の一撃が必ず会心になる） / Lv200 奇跡の号令（ペット全員を全快し、45秒間攻撃・守備を20%上げる） |
| サブ職業のとき | 本人与ダメ0とペット強化・被ダメ軽減はサブでも有効。係数と解放段階はサブ実効Lvを使う。 |
| 転職条件 | 魔物使いLv30＋パラディンLv30。 |
| その他 | ペット基礎補正+20〜40%に図鑑数補正を加え、合計最大×2.0。Lv120被ダメ-10%、Lv210-20%。指揮: Lv1攻撃の号令(ペット攻撃+30%)、30標的マーク(0ダメの一撃で15秒印・ペット与ダメ×1.3)、60連携(合図で+30%・連続で最大+60%)、100守りの号令(被ダメ-30%)、120応援チャージ(HP5〜20%回復・10秒攻撃+20%)、180陣地の旗(30秒・周囲8マス攻撃+20%/被ダメ-20%/毎秒1%回復)。指揮ゲージ0〜100は標的・連携で増え、号令・応援・旗で減る。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | B
こうげき | E
しゅび | A
まりょく | C
魔法しゅび | A
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
