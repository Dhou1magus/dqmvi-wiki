# モンスターロード

本人の与ダメージを0にして、ペットの全能力・耐久を大きく伸ばす指揮専門の職業。標的・連携・号令・応援・旗の「指揮」で、ペットを動かし続ける。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 攻撃はペットに任せ、作戦・対象・必殺技で指揮する（本人が殴ってもダメージは出ない）。集中攻撃命令（Lv20・MP5）：視線の先128マスまでの敵を指定。命じたペットは30秒間 攻撃+20%。号令の特技：Lv54 防御陣形／78 癒しの号令／102 奮起の号令／126 緊急招集／150 王者の号令。左クリック長押し：攻撃の号令／しゃがみ長押し：守りの号令。ペットが攻撃する直前に、合図キーで連携。 |
| 武器の補正 | 全武器 E（与ダメ×0.30） |
| 魔法の補正 | 回復蘇生・ホイミ・全体回復・再生・蘇生・状態回復×1.0、その他×0.3。 |
| 必殺技 | Lv200 奇跡の号令（ペット全員を全快し、45秒間攻撃・守備を20%上げる） / Lv300 総攻撃指令（ペット全員の次の一撃が必ず会心になる） |
| サブ職業のとき | 本人の与ダメージ0と、ペット強化・被ダメージ軽減はサブでも有効。係数と解放段階は、サブの実効Lvで決まる。 |
| 転職条件 | 魔物使いLv30＋パラディンLv30。 |
| その他 | ペットの基礎補正+20〜40%に図鑑数の補正を足し、合計は最大×2.0。被ダメージ軽減：Lv120で-10%、Lv210で-20%。指揮 Lv1 攻撃の号令：ペットの攻撃+30%。指揮 Lv30 標的マーク：0ダメージの一撃で15秒間の印。ペットの与ダメージ×1.3。指揮 Lv60 連携：合図で+30%、続けると最大+60%。指揮 Lv100 守りの号令：被ダメージ-30%。指揮 Lv120 応援チャージ：HP5〜20%回復・10秒間 攻撃+20%。指揮 Lv180 陣地の旗：30秒間、周囲8マスで攻撃+20%・被ダメージ-20%・毎秒1%回復。指揮ゲージ（0〜100）：標的・連携で増え、号令・応援・旗で減る。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | B
こうげき | E
しゅび | A
まりょく | C
魔法しゅび | A
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
