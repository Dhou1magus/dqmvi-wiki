# 吟遊詩人

竪琴の「歌」で場を作る支援職。引き寄せ・蘇生・同士討ち・踊り・反響・稼ぎと、味方全体の回復・強化を担う。遠距離ほど強い射撃補正も持つ。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 竪琴を持ち、右クリックで周囲の仲間とペットを回復・強化、左クリックで音波攻撃。発動歌: Lv20癒しの旋律・39セイレーンの歌(敵を引き寄せる)・48力の歌・67鎮魂歌(気絶ペットを最大3体復帰)・76魔守の歌・85魅了の歌(15秒同士討ち)・113踊りの歌(10秒行動不能・討伐時ドロップ抽選2回)・141天籟の歌。トグル歌(特技メニューでON/OFF・同時1曲、Lv210で2曲): 58守の歌・95速さの歌・132共鳴の歌(味方の一撃の30%が周囲へ反響)・150戦場のBGM(経験値・ゴールド+25%)。 |
| 武器の補正 | 最高 竪琴=SSS（×1.50） / 最低 勇者の剣・杖・大鎌=E（×0.30） |
| 魔法の補正 | バギ×0.7、その他×0.3。 |
| 必殺技 | Lv200 終焉の譜（周囲24マスの敵全員へ攻撃力18倍の音波ダメージを与え、8秒間鈍足にする） / Lv300 英雄譚（パーティ全員とペットを全快させ、攻撃・守備を60秒間50%上げる(状態異常も解除)） |
| サブ職業のとき | 距離補正、歌、歌唱中移動低下、実績数による歌強化はサブでも有効。竪琴の回復量はメイン・サブの良い方の竪琴適正で変化する。 |
| 転職条件 | レンジャーLv30＋スーパースターLv30。 |
| その他 | 観客動員: 歌の範囲内の味方1体ごとに発動歌の持続+10%(上限+100%)。歌の範囲16マス→Lv30で20→Lv180で24。歌唱中の移動-30%はLv90で-15%、Lv300で無し。Lv120実績10個ごとに歌+1%(上限+15%)。ボス級には引き寄せ・魅了・踊りが効かない(Lv300で魔王系以外に半分の時間)。4マス以内は遠距離与ダメ50%、8マス超は1マスごと+2%。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。
