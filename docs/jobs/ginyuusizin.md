# 吟遊詩人

竪琴の「歌」で場を作る支援職。引き寄せ・蘇生・同士討ち・踊り・反響・稼ぎと、味方全体の回復・強化を受け持つ。遠くの敵ほど強くなる射撃補正も持つ。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 竪琴を持って右クリック：周囲の仲間とペットを回復・強化。竪琴を持って左クリック：音波攻撃。発動歌：Lv20 癒しの旋律／39 セイレーンの歌（敵を引き寄せる）／48 力の歌／67 鎮魂歌（気絶ペットを最大3体復帰）。発動歌：Lv76 魔守の歌／85 魅了の歌（15秒同士討ち）／113 踊りの歌（10秒行動不能・倒すとドロップ抽選2回）／141 天籟の歌。トグル歌：特技メニューでON/OFF。同時に1曲（Lv210で2曲）。トグル歌：Lv58 守の歌／95 速さの歌／132 共鳴の歌（味方の一撃の30%が周囲へ反響）／150 戦場のBGM（経験値・ゴールド+25%）。 |
| 武器の補正 | 最高 竪琴=SSS（×1.50） / 最低 勇者の剣・杖・大鎌・ドリル=E（×0.30） |
| 魔法の補正 | バギ×0.7、その他×0.3。 |
| 必殺技 | Lv200 終焉の譜（周囲24マスの敵全員へ攻撃力18倍の音波ダメージを与え、8秒間鈍足にする） / Lv300 英雄譚（パーティ全員とペットを全快させ、攻撃・守備を60秒間50%上げる(状態異常も解除)） |
| サブ職業のとき | サブでも有効：距離補正・歌・歌唱中の移動低下・実績数による歌の強化。竪琴の回復量は、メインとサブの良い方の竪琴適正で変わる。 |
| 転職条件 | レンジャーLv30＋スーパースターLv30。 |
| その他 | 観客動員：歌の範囲内の味方1体ごとに、発動歌の持続+10%（上限+100%）。歌の範囲：16マス → Lv30で20マス → Lv180で24マス。歌唱中の移動：-30% → Lv90で-15% → Lv300で低下なし。Lv120：実績10個ごとに歌+1%（上限+15%）。ボス級には引き寄せ・魅了・踊りが効かない（Lv300で、魔王系以外には半分の時間効く）。遠距離の与ダメージ：4マス以内は50%、8マスを超えると1マスごとに+2%。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
