# 忍者

短剣・爪・ブーメランを使う高速物理職。二刀流と忍び足が特徴。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 右手と左手に対応武器を装備すると二刀流になる。特技：クロスカッター・パワフルスロー・超パワフルスロー・デュアルカッター・ギガスロー。属性ブーメラン：バーニングバード・フローズンバード・シャインスコール。忍び足I・IIも使い分ける。 |
| 武器の補正 | 最高 ブーメラン・鎖鎌=SSS（×1.50） / 最低 斧=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 アクロバットスター（30秒間、みかわし率が大きく上がる） / Lv300 トリックゾーン（対象と周囲にダメージを与え、幻惑させて守備力を2段階下げる） |
| サブ職業のとき | 二刀流はサブでも有効（左手武器の追加攻撃が出る）。適正はメインとサブの良い方を使う。 |
| 転職条件 | 盗賊Lv30＋魔法戦士Lv30。 |
| その他 | 杖・弓・ブーメランなど、二刀流の左手に置けない武器がある。忍び足中は、決められた距離まで敵に見つからない。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | B
MP | C
こうげき | S !

```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
