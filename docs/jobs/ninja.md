# 忍者

短剣・爪・ブーメランを使う高速物理職。二刀流と忍び足が特徴。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 右手と左手へ対応武器を装備すると二刀流になる。クロスカッター・パワフルスロー・超パワフルスロー・デュアルカッター・ギガスローと属性ブーメラン(バーニングバード・フローズンバード・シャインスコール)、忍び足I・IIを使い分ける。 |
| 武器の補正 | 最高 ブーメラン=SSS（×1.50） / 最低 斧=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 アクロバットスター（30秒間、みかわし率が大きく上がる） / Lv300 トリックゾーン（対象と周囲にダメージを与え、幻惑させて守備力を2段階下げる） |
| サブ職業のとき | 二刀流はサブでも有効。左手武器の追加攻撃が発生し、適正はメイン・サブの良い方を使う。 |
| 転職条件 | 盗賊Lv30＋魔法戦士Lv30。 |
| その他 | 杖・弓・ブーメランなど二刀流の左手に置けない武器がある。忍び足中は決められた距離まで敵に見つからない。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | B
MP | C
こうげき | S !
しゅび | C
まりょく | E
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **1種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| スライムトレイ | ×1.04 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
