# 道具使い

槍・弓を扱う実用型物理職。槍の単体・多段・範囲特技を順に習得する。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 槍を装備して狼牙突き・獣突き・雷鳴突き・一閃突き・五月雨突き・ジゴスパーク・超さみだれ突きを使う。回復や補助は所持アイテムと組み合わせる。 |
| 武器の補正 | 最高 槍・弓=SS（×1.35） / 最低 杖=D（×0.70） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 強化ガジェット零式I（30秒間、その中で与えるダメージが2倍になる魔法陣を置く） / Lv300 アブソリュートレイI（敵1体にダメージを与え、呪文耐性と守備力を2段階下げる） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 遊び人Lv30＋僧侶Lv30。 |
| その他 | 道具効果倍率そのものは道具マスターの習得技。道具使いだけでは自動倍率は付かない。一閃突きはメタル系にも1/4で一撃。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び


ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
