# ソウルマスター

討伐時に獲得したモンスターへ憑依し、能力・魔法・系統特性・固有攻撃を借りる変身職。憑依中はHP・MPもモンスターのものになる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 敵を本人か所有ペットで倒して魂と憑依を集め、憑依切替(Lv1)で選ぶ。憑依中は左クリックを1秒溜めるとAI型別の固有攻撃。憑依解除(Lv1)で元の姿へ戻る。魂の一撃(20)・ソウルシールド(60)・魔魂解放(90・魂50消費)・憑依深化(120・60秒効率+15%)・魂喰い(150)。憑依先の魔法1〜5は登録スロット8〜12へ自動登録され、憑依すると三人称視点になる。 |
| 武器の補正 | 最高 拳=B（×1.00） / 最低 バニラ剣・剣・勇者の剣・槍・短剣・杖・棍・爪・ハンマー・斧・ムチ・弓・ブーメラン・銃・戦輪・竪琴・大鎌・戦籠手=E（×0.30） |
| 魔法の補正 | メラ・ギラ・イオ・デイン・バギ・ドルマ・ヒャド・その他攻撃・回復蘇生・ホイミ・全体回復・再生・蘇生・補助・状態回復・弱体×0.7、魔法剣×0.3。 |
| 必殺技 | Lv200 百鬼夜行（憑依獲得済みからランダム5体の幻影が10秒間攻撃する） / Lv300 完全憑依（60秒間、能力反映率を30%上げて上限を突破する） |
| サブ職業のとき | 魂・憑依獲得・系統特性・固有攻撃はメインとサブの両方で有効。憑依中は武器攻撃値・倍率・適正が乗らない。 |
| 転職条件 | 盗賊Lv30＋魔物使いLv30。 |
| その他 | 憑依中のHP・MPはモンスターのHP・MP×Lv倍率×効率。憑依中にHPが尽きると死なずに憑依が解け、元の姿へ戻る。解除後(自分で解除・HP0とも)1分間は次の憑依ができない。戻ったときのHP・MPは憑依前の値(減っていれば減ったまま)。借用能力はモンスターLv倍率×効率。魂は最大100、1個ごと効率+0.1%。通常1/(ランク×5)、転生×10、メタル×30、ボス1/300で憑依獲得。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | D
MP | C
こうげき | D
しゅび | D
まりょく | B
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
