# ソウルマスター

倒して手に入れたモンスターに憑依し、能力・魔法・系統特性・固有攻撃を借りる変身職。憑依中はHP・MPもモンスターのものになる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 本人か自分のペットで敵を倒して、魂と憑依を集める。憑依切替（Lv1）：憑依先を選ぶ／憑依解除（Lv1）：元の姿に戻る。憑依中に左クリックを1秒溜める：AIの型ごとの固有攻撃。特技：Lv20 魂の一撃／60 ソウルシールド／90 魔魂解放（魂50消費）／120 憑依深化（60秒間 効率+15%）／150 魂喰い。憑依先の魔法1〜5は、登録スロット8〜12へ自動で登録される。憑依すると三人称視点になる。 |
| 武器の補正 | 最高 拳=B（×1.00） / 最低 バニラ剣・剣・勇者の剣・槍・短剣・杖・棍・爪・ハンマー・斧・ムチ・弓・ブーメラン・銃・戦輪・竪琴・大鎌・戦籠手・ドリル・鎖鎌=E（×0.30） |
| 魔法の補正 | メラ・ギラ・イオ・デイン・バギ・ドルマ・ヒャド・その他攻撃・回復蘇生・ホイミ・全体回復・再生・蘇生・補助・状態回復・弱体×0.7、魔法剣×0.3。 |
| 必殺技 | Lv200 百鬼夜行（憑依獲得済みからランダム5体の幻影が10秒間攻撃する） / Lv300 完全憑依（60秒間、能力反映率を30%上げて上限を突破する） |
| サブ職業のとき | 魂・憑依の獲得・系統特性・固有攻撃は、メインでもサブでも有効。憑依中は、武器の攻撃値・倍率・適正が乗らない。 |
| 転職条件 | 盗賊Lv30＋魔物使いLv30。 |
| その他 | 憑依中のHP・MP＝モンスターのHP・MP×Lv倍率×効率。憑依中にHPが尽きても死なず、憑依が解けて元の姿に戻る。解除後（自分で解除・HP0のどちらも）1分間は次の憑依ができない。戻ったときのHP・MPは憑依前の値（減っていれば減ったまま）。借りる能力＝モンスターのLv倍率×効率。魂は最大100。1個ごとに効率+0.1%。憑依の獲得：通常1/(ランク×5)・転生×10・メタル×30・ボス1/300。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | D
MP | C
こうげき | D
しゅび | D
まりょく | B

```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
