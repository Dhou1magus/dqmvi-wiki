# 魔物使い

ムチ・斧・弓を扱う、モンスターと一緒に戦いやすい物理職。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | ペットを連れ、本人は愛のムチ・ねむり打ち・しばり打ち・双竜打ち・疾風迅雷・地這い大蛇で援護する。魔物の心得1〜4は覚えているだけで常に効く。ペットの作戦は別途ペット操作から設定する。 |
| 武器の補正 | 最高 ムチ=SSS（×1.50） / 最低 勇者の剣=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 ビーストモード（30秒間、自分を大きく強化する） / Lv300 流星爪牙（敵1体に大ダメージ） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 遊び人Lv30＋魔法使いLv30。 |
| その他 | モンスターロードとは別職。本人の攻撃を禁止したり、ペット能力を直接倍化する職業ではない。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | D
こうげき | A
しゅび | C
まりょく | E
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
