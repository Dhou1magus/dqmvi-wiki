# 魔法戦士

物理と魔力を両立し、剣・槍と魔法剣を使う複合アタッカー。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 敵の弱点属性に合わせて、魔法剣や特技を選ぶ。特技：ドラゴン斬り・れんごく斬り・メタル斬り・はやぶさ斬り・ミラクルソード・魔神斬り・超はやぶさ斬り・大まじん斬り。必要に応じて、攻撃・補助の魔法も使う。 |
| 武器の補正 | 最高 剣=SSS（×1.50） / 最低 棍・ブーメラン=E（×0.30） |
| 魔法の補正 | 魔法剣×1.2、メラ・ギラ・ヒャド・補助・弱体×1.0、その他×0.3。 |
| 必殺技 | Lv200 マジックルーレット（MPを999回復する） / Lv300 エナジーフォール（MPを全部使い切って、対象と周囲へ光属性の範囲攻撃） |
| サブ職業のとき | この職だけの常時パッシブはない（共通の能力加算・習得技・良い方の適正だけが有効）。 |
| 転職条件 | 魔法使いLv30＋戦士Lv30。 |
| その他 | マジックルーレット：MP999回復。エナジーフォール：全MPを使う光の範囲攻撃。魔神斬り・大まじん斬り：メタル系もそれぞれ1/4・1/2で一撃。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | S !
MP | B
こうげき | S !
しゅび | S !
まりょく | S !
魔法しゅび | C
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
