# 鬼神闘士

HPが減るほど通常攻撃が強くなる高リスク前衛。回復半減・守備低下の弱点を持つ。戦籠手(ロケットパンチ)の職。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 斧・ハンマー・戦籠手で接近し、HPを低く保って攻撃する。戦籠手の特技はMPではなくHPを消費する(鬼砕き5・修羅連拳10・鉄壁の構え8・地裂衝15・鬼神カウンター20・鬼哭爆拳30)。戦籠手は左クリック1.5秒ためで貫通ロケットパンチ(7マスで折り返し・両手なら2個・待ち1秒)。致死回避の再使用間隔と回復量に注意する。 |
| 武器の補正 | 最高 斧・戦籠手=SSS（×1.50） / 最低 杖・弓・ブーメラン・銃・竪琴=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 捨て身の咆哮（現在HPを半分消費し、60秒間攻撃力が1.5倍になる） / Lv300 遺言の一撃（敵1体へ、HP満タン時2倍からHP1付近で最大20倍になる防御無視攻撃） |
| サブ職業のとき | 固有の攻撃倍率・回復半減・守備×0.8・低HP速度・不屈・会心はサブでも実効Lv基準で有効。 |
| 転職条件 | バトルマスターLv30＋パラディンLv30。 |
| その他 | 攻撃上限は就任時×2.0からLv300で×3.0。受ける回復50%、守備80%。Lv150不屈、Lv240以降低HP会心。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。
