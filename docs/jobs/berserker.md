# 鬼神闘士

HPが減るほど通常攻撃が強くなる、高リスクの前衛。弱点：受ける回復が半分・守備が下がる。戦籠手（ロケットパンチ）の職業。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 斧・ハンマー・戦籠手で接近し、HPを低く保って攻撃する。戦籠手の特技はMPではなくHPを使う：鬼砕き5・修羅連拳10・鉄壁の構え8・地裂衝15・鬼神カウンター20・鬼哭爆拳30。戦籠手は左クリック1.5秒ためで、貫通ロケットパンチ（7マスで折り返し・両手なら2個・待ち1秒）。致死回避の再使用間隔と回復量に注意。 |
| 武器の補正 | 最高 斧・戦籠手=SSS（×1.50） / 最低 杖・弓・ブーメラン・銃・竪琴=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 捨て身の咆哮（現在HPを半分消費し、60秒間攻撃力が1.5倍になる） / Lv300 遺言の一撃（敵1体へ、HP満タン時2倍からHP1付近で最大20倍になる防御無視攻撃） |
| サブ職業のとき | サブでも実効Lv基準で有効：固有の攻撃倍率・回復半減・守備×0.8・低HP時の速度・不屈・会心。 |
| 転職条件 | バトルマスターLv30＋パラディンLv30。 |
| その他 | 攻撃の上限：就任時×2.0 → Lv300で×3.0。受ける回復50%、守備80%。Lv150で不屈、Lv240以降は低HP時に会心。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
