# 秘境ハンター

鉱石・宝箱・新バイオームを見つけ、探索の成果で強くなる探索職。罠で足を止め、跳躍で高所を取り、急襲で叩く狩人でもある。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 常に出る探知表示を頼りに、採掘・探索する。壁越しに見る（枠線表示）：Lv20 採石眼／50 風読み／70 地脈感知／110 宝の羅針盤。秘境跳躍（Lv90）：真上へ100マス跳んで4秒浮遊。降下中は落下ダメージなし。野営術（Lv130・30分に1回）・魔物追跡（Lv150）。迷宮探知（Lv170）：未訪問の全ダンジョンの方角と距離。魔王迷宮探知（Lv200）：未訪問の魔王迷宮の方角と距離。 |
| 武器の補正 | 最高 ドリル=SSS（×1.50） / 最低 勇者の剣・杖・ブーメラン=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 大発見（60秒間、周囲48マスの鉱石・宝箱・隠しブロックを壁越しに表示する） / Lv300 冒険録（60秒間、発見バイオーム数に応じて全能力が上がる（15種で+15%）） |
| サブ職業のとき | サブでも実効Lv基準で有効：鉱脈探知・採掘速度・ダンジョンと新バイオームの補正・鉱石増加・ルーラ無制限・宝箱の昇格。 |
| 転職条件 | スーパースターLv30＋盗賊Lv30。 |
| その他 | 探索：Lv30 鉱脈探知／60 採掘+30%／120・210 ダンジョンで全能力+10%・+15%。探索：Lv180 鉱石+50%／240 ルーラ無制限／300 宝箱が1等級上がる。狩人：Lv1 秘境ボーナス（今いるバイオームのランク×5%）／30 落とし穴の罠／60 急襲（3マス以上の落下攻撃）。狩人：Lv90 スパイクの罠・秘境跳躍（特技）／150 粘着の罠／180 遺跡の痕跡（メインのみ・道具屋で鑑定）。罠の使い方：作業台で作って地面に置く使い捨てアイテムです（特技ではありません）。落とし穴の罠＝板材4＋ツタ2／スパイクの罠＝鉄鉱石3／粘着の罠＝スライムゼリー2（各1回に2個）。同時に置ける数はLv30で3・Lv150で5・Lv240で8（サブ職業は半分）。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
