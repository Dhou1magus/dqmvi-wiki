# 秘境ハンター

鉱石・宝箱・新バイオームを発見し、探索成果で強くなる探索職。罠で足を止め、跳躍で高所を取り、急襲で叩く狩人でもある。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 常時の探知表示を頼りに採掘・探索する。採石眼(Lv20)・風読み(50)・地脈感知(70)・宝の羅針盤(110)で鉱石や宝箱を壁越しに見る(枠線表示)。秘境跳躍(90)は真上へ100マス跳んで4秒浮遊し、降下中は落下ダメージ無し。野営術(130)・魔物追跡(150)。迷宮探知(170)は未訪問の全ダンジョン、魔王迷宮探知(200)は未訪問の魔王迷宮の方角と距離を示す。 |
| 武器の補正 | 最高 短剣・ハンマー・銃=S（×1.20） / 最低 勇者の剣・杖・ブーメラン=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 大発見（60秒間、周囲48マスの鉱石・宝箱・隠しブロックを壁越しに表示する） / Lv300 冒険録（60秒間、発見バイオーム数に応じて全能力が上がる（15種で+15%）） |
| サブ職業のとき | 鉱脈探知、採掘速度、ダンジョン・新バイオーム補正、鉱石増加、ルーラ無制限、宝箱昇格はサブでも実効Lv基準。 |
| 転職条件 | スーパースターLv30＋盗賊Lv30。 |
| その他 | Lv30鉱脈探知、60採掘+30%、120/210ダンジョン全能力+10/15%、180鉱石+50%、240ルーラ無制限、300宝箱1等級上昇。狩人: Lv1秘境ボーナス(居る場所のバイオームランク×5%)、30落とし穴の罠、60急襲(3マス以上の落下攻撃)、90スパイクの罠・秘境跳躍(特技)、150粘着の罠、180遺跡の痕跡(メインのみ・道具屋で鑑定)。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | A
MP | D
こうげき | B

まりょく | B

```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
