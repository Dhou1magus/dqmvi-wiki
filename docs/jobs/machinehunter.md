# 魔導銃士

魔法弾を撃つ銃だけを新武器として使う中〜遠距離職。射撃は攻撃力70%＋魔力30%で計算し、銃ユニット(ハンドガン・マグナム・ショットガン・ライフルなど)で連射・散弾・貫通・スコープが変わる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 銃を持って左クリックで射撃し、1回ごとにMPを消費する。弾切れで自動リロード(カチャ→カチッの音)、しゃがみ右クリックで手動リロード。ライフルは右クリック長押しで10倍スコープ。弾がモンスターの頭判定を通ると威力2倍(HEADSHOT)。特技: Lv20火炎魔法弾・54氷結魔法弾・78雷撃魔法弾(3連射)・102貫通魔法弾(守備70%貫通)・126散弾魔法弾(5発)・150魔導オーバーロード(30秒威力+25%)。ホットバーで右クリックすると銃ユニット枠と交換できる。 |
| 武器の補正 | 最高 銃=SSS（×1.50） / 最低 バニラ剣・剣・勇者の剣・槍・短剣・杖・棍・爪・拳・ハンマー・斧・ムチ・弓・ブーメラン=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 魔導掃射陣（周囲の敵へ自動照準で連続射撃する） / Lv300 星穿終焉砲（視線方向へ超長距離の防御無視砲撃を放ち、直線上の敵を貫く） |
| サブ職業のとき | サブでも魔法弾MP軽減・銃の混合能力計算・装弾数・リロード・守備貫通が実効Lvで有効。守備貫通とリロード短縮はメイン時の半分。 |
| 転職条件 | 道具使いLv30＋魔法戦士Lv30。 |
| その他 | 魔法弾は武器段階により1射撃MP1〜8。実効Lv60/150/240で消費MP-1/-2/-3(最低1)。Lv30/210で装弾数、Lv90/210でリロード時間が改善。基本守備貫通10%、Lv120で20%、Lv270で30%。4マス以内は威力-30%、Lv300で射撃威力+15%。銃ユニットは鍛冶で改造できる。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | B
MP | C
こうげき | S !
しゅび | D
まりょく | A
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
