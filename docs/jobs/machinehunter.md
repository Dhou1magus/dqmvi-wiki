# 魔導銃士

魔法弾を撃つ銃だけを新武器として使う、中〜遠距離職。射撃の威力は、攻撃力70%＋魔力30%で計算。銃ユニット（ハンドガン・マグナム・ショットガン・ライフルなど）で、連射・散弾・貫通・スコープが変わる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 銃を持って左クリックで射撃（1回ごとにMPを使う）。弾切れで自動リロード（カチャ→カチッの音）／しゃがみ右クリックで手動リロード。ライフルは右クリック長押しで10倍スコープ。弾がモンスターの頭判定を通ると威力2倍（HEADSHOT）。特技：Lv20 火炎魔法弾／54 氷結魔法弾／78 雷撃魔法弾（3連射）／102 貫通魔法弾（守備70%貫通）／126 散弾魔法弾（5発）／150 魔導オーバーロード（30秒間 威力+25%）。ホットバーで右クリックすると、銃ユニットの枠と交換できる。 |
| 武器の補正 | 最高 銃=SSS（×1.50） / 最低 バニラ剣・剣・勇者の剣・槍・短剣・杖・棍・爪・拳・ハンマー・斧・ムチ・弓・ブーメラン=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 魔導掃射陣（周囲の敵へ自動照準で連続射撃する） / Lv300 星穿終焉砲（視線方向へ超長距離の防御無視砲撃を放ち、直線上の敵を貫く） |
| サブ職業のとき | サブでも実効Lvで有効：魔法弾のMP軽減・銃の混合能力計算・装弾数・リロード・守備貫通。サブのときの守備貫通とリロード短縮は、メイン時の半分。 |
| 転職条件 | 道具使いLv30＋魔法戦士Lv30。 |
| その他 | 魔法弾の消費MP：武器の段階により1射撃1〜8。消費MPの軽減：実効Lv60/150/240で-1/-2/-3（最低1）。装弾数：Lv30/210で改善／リロード時間：Lv90/210で改善。守備貫通：基本10% → Lv120で20% → Lv270で30%。4マス以内は威力-30%／Lv300で射撃威力+15%。銃ユニットは鍛冶で改造できる。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

HP | B
MP | C
こうげき | S !

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。

## 習得スキル

職業のレベルで覚え、職業スキル画面でSPの続くかぎり24枠までセットできます。効果があるのはセットしたスキルだけです。SPはセットに使うポイントです。

| Lv | 種類 | 名前 | 効果 | SP |
| ---: | :--: | --- | --- | ---: |
| 30 | 能力アップ | 攻撃力+3 | 装弾数が8発になる | 4 |
| 60 | 能力アップ | 魔力+3 | 徹甲弾の扱いを覚える | 4 |
| 90 | 能力アップ | 最大HP+10 | リロード時間が20%短くなる | 8 |
| 100 | 持込 | 魔導銃士の魔法・特技 | 魔導銃士の射撃技を、いまの職業のままでも使えるようになる | 50 |
| 120 | 能力アップ | 守備力+5 | 射撃の基本守備貫通が20%になる | 8 |
| 150 | 能力アップ | 魔力+5 | 火炎弾・冷却弾の扱いを覚える | 8 |

| 200 | 必殺技 | 魔導掃射陣 | 周囲の敵へ自動照準で連続射撃する | 100 |

## 構えられる盾

この職業で使える盾は **4種** です。守備倍率の高い順に並べています。

| 盾 | しゅび | 魔法しゅび | 構え中 |
| --- | ---: | ---: | ---: |
| シールドあにきの盾 | ×1.2 | ×1.2 | ×4 |
| キトンシールド | ×1.11 | ×1.11 | ×3 |
| ライトシールド | ×1.06 | ×1.06 | ×3 |
| おなべのふた | ×1.01 | ×1 | ×3 |

盾は[オフハンドに持って右クリック長押し](/items/shields)で構えます。
