# 遊び人

平均的な能力で、ムチやブーメランと予測不能な必殺技を楽しむ変則職。多くの上級職の転職元になる。

## 職業の特徴

ゲーム内の職業表「職業の特徴」に載っている内容です。

| 項目 | 内容 |
| --- | --- |
| 操作 | 通常攻撃と特技(Lv20/70 お宝探しI・II、110 グランドクロス、150 グランドネビュラ)を使い分ける。パルプンテは結果がランダムなので、劣勢を変える切り札向き。 |
| 武器の補正 | 最高 ブーメラン=SS（×1.35） / 最低 勇者の剣・杖・拳=E（×0.30） |
| 魔法の補正 | 自前の職業魔法なし。全系統×0.3。 |
| 必殺技 | Lv200 パルプンテ（なにが起こるかわからない） / Lv300 びっくりルーレット（まわりへどれかの属性で攻撃し、その属性への耐性を下げる） |
| サブ職業のとき | この職固有の常時パッシブはない。共通の能力加算・習得技・良い方の適正だけが有効。 |
| 転職条件 | 初期職のため条件なし。 |
| その他 | Lv200のパルプンテは効果を選べない。安定火力より遊びと逆転性を重視する職業。 |

サブ職業の共通のきまりは[職業一覧](/jobs/#subjob-rules)にまとめています。

## 能力の伸び

```stats
HP | C
MP | D
こうげき | C
しゅび | D
まりょく | C
魔法しゅび | D
```

ランクは SSS がいちばん高く、SS・S・A・B・C・D・E の順に下がります。
