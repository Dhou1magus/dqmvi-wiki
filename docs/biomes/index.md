::: tip 湧く場所が決まっていないモンスター
MODは「通常」「やや強い」「強い」「レア」といった強さ別のまとまりからも抽選します。
そちらから湧くモンスターは特定のバイオームに紐づいていないため、この一覧には出てきません。
:::
