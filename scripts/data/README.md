# scripts/data

## 固定データ（管理者が更新する）

| ファイル | 中身 | 版 |
| --- | --- | --- |
| `monster-extras.json` | モンスターの系統・弱点・活動時間・ドロップ・呪文・ランク（ゲーム内の図鑑と同じ項目） | 0.28.16 |
| `equipment.json` | 装備の数値・武器種・特殊効果（ゲーム内のツールチップと同じ項目） | 0.28.16 |
| `job-features.json` | 職業の特徴・転職条件（ゲーム内の職業表「職業の特徴」と同じ内容） | 0.28.16 |
| `material-ranks.json` | 素材のランクと鉱石のランク・深さ（ゲーム内の「素材取得一覧表」「鉱石取得一覧表」と同じ内容） | 0.28.16 |
| `item-sources.json` | 素材などの入手方法のうち、jar 内の表データから分かるもの（魚交換所・農業・採取・釣り・精錬） | 0.25.84 |

載せてよいのは **ゲーム内でZキーを押して開く DQM メニューで確認できる事項** だけです（2026-09-05 の決まり）。
メニューに出ない内部の値（内部ID・区分フラグ・確率・計算式・出現場所・入手経路）は載せません
（2026-09-06 に、それまで残していた出現場所と宝箱・鍛冶・店などの入手経路も削除しました）。
これらを作り直す道具はリポジトリに置きません。

`name-index.json` は gen-*.mjs が書き出す作業用のファイルです。

`monster-kinds.json` は **手で書くファイル** です。モンスター図鑑の絞り込みボタン（転生・ボス・コインボス）で
どのモンスターを出すかを決めます。書き方はファイルの中の「_説明」を見てください。gen-*.mjs は触りません。

`monster-blank.json` も **手で書くファイル** です。ここに書いたモンスターは、名前と図鑑No.だけ残して
中身（ステータス・生態・ドロップ品・呪文）を空欄にし、逆引き・系統の一覧にも出しません
（2026-09-05 の決まり: 0.25.84 のあとに増えたランク5以上のモンスター。出してよくなるまでそのまま）。
中身を出すときは行を消して gen-monster-pages / gen-drop-pages / gen-item-pages を流します。

`weapon-blank.json` も **手で書くファイル** です。`kinds` に書いた武器種は、武器一覧ページ（/items/weapons）で
名前だけ残して こうげき・攻撃倍率・特殊効果 の欄を空欄にします（2026-09-06 の指示: 銃・戦輪・竪琴）。
出してよくなったら種類名を消して gen-item-pages.mjs を流し直します。
